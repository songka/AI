台达 AS228T PLC Skill

当前版本：2.1.1

用途：针对 Delta AS228T / AS228T-A 与 ISPSoft 的程序设计、解释、审查、重构和排障。

安装：
1. 使用 package 文件夹，或解压 package.zip。
2. 将文件夹重命名为 delta-as228t-plc（可选但推荐）。
3. 放入 AI Agent 的 skills 目录。

注意：
- 本 Skill 不支持 DVP、AH 或其他品牌 PLC。
- 所有输出均应先在 ISPSoft 编译并离线测试。
- 涉及接线、输出、运动、强制、旁路或在线下载时，必须遵守 references/safety-boundaries.md。
- 长期研究与升级计划见 SKILL_MAINTENANCE_PLAN.md，历史发布见 RELEASES.md。
