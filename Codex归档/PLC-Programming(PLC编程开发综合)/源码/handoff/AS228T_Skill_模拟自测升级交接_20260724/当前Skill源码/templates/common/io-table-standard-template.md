# I/O 表交付模板

交付时建立以下页签或等价表格：

1. 说明与规则：版本、适用机型、地址规则、所有权规则、安全边界。
2. 地址分区：起止地址、用途、生产者、消费者、保持、状态、负责人。
3. 物理 DI/DO：地址、符号、模块/槽/通道、端子、类型、有效电平、安全状态、滤波、设备、图纸号。
4. 机器人接口：D 字位、方向、EIP Assembly 或离散 I/O、生产者、消费者、握手、超时、失效值。
5. 轴与 CANopen：节点/轴、D 地址、对象索引、PDO/SDO、数据类型、字序、比例、单位、更新周期、异常处理。
6. 报警：ID、Active、Latched、级别、触发、复位、HMI 文本、响应。
7. HMI 手动：请求位、反馈位、模式、权限、互锁、超时和松开/掉线行为。
8. 通信数据：协议、连接、方向、地址、长度、类型、端序、周期、超时、质量位和来源。
9. 上下站联机：对接模式、信号名称、方向、生产者、消费者、请求/确认关系、保持条件、清除条件、超时、断线/重上电恢复、连接器针脚和图纸来源。

每张表保留“生产者/唯一写入者”“消费者”“状态”“来源”列，并在发布前检查重复地址、未定义方向和缺失失效值。
