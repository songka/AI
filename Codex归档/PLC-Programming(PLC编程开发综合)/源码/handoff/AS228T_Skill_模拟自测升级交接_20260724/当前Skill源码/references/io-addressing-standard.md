# AS228T I/O 与接口地址规范

## 1. 适用范围

用于 AS228T-A + ISPSoft 3.19及以上、ST项目的物理 I/O、机器人、CANopen、脉冲轴、报警和 HMI 手动接口。AS 系列编程手册设备表支持 `D0.0`～`D29999.15` 位访问。

## 2. 地址总则

- 设备和顺控逻辑优先使用有意义的符号；D/X/Y 只在映射与接口层出现。
- 一个地址只有一个生产者/写入者，可有多个消费者/读取者。
- 一个 D 字若按位使用，16 位全部归同一接口块管理；不得由其他 POU、HMI、通信表或整字指令写入。
- 命令与状态分字、PLC→外部与外部→PLC 分区、活动报警与锁存报警分区。
- 32 位和浮点量使用连续两个 D，表中必须记录低/高字顺序、符号、比例和单位。
- 通信接收数据先进入接收区，完成在线、超时、范围和序号校验后，才复制到控制变量。
- 命令、状态、实时 I/O 默认不保持；配方和校准参数才允许进入经项目核实的保持区。

### 3.1 轴物理输入固定起点

- 轴1～20正向物理限位：D200.0起，轴n为 `D[200+INT((n-1)/16)].[(n-1) MOD 16]`。
- 轴1～20反向物理限位：D202.0起，轴n为 `D[202+INT((n-1)/16)].[(n-1) MOD 16]`。
- 轴1～20原点传感器：D204.0起，轴n为 `D[204+INT((n-1)/16)].[(n-1) MOD 16]`。

### 3.2 伺服缓存

- D100～D139与每轴永久参数块的偏移+0～+39完全一致。
- 核心字段：正/反软件限位、每圈脉冲数、加速度、减速度、手动低/中/高速、自动速度、回原速度、容差、原点偏移、电子齿轮、减速点、工艺慢速、最大速度、点动距离、配置、轴类型、版本和校验码。
- HMI只编辑工作缓存并提出加载/校验/应用/保存请求；PLC参数管理校验后才写入D20000～D20799永久参数。

## 4. 字位命名与所有权

- 命令字：`Cmd_*`，状态字：`Sts_*`，请求：`Req_*`，确认：`Ack_*`。
- 示例：`D2000.0 = Rbt_StartReq`，`D2010.0 = Rbt_Ready`；不要让机器人和 PLC 同写 D2000。
- 位号固定为 0～15；未使用位写 `Reserved`，不得临时借用。
- 表中必须记录：方向、生产者、消费者、访问权限、更新方式、超时、失效值、保持属性。

## 5. 机器人接口

PLC→Robot 与 Robot→PLC 必须使用不同字。建议至少包括：在线、就绪、自动允许、启动请求/确认、停止/保持、复位请求/确认、回原点、忙、完成、报警、程序号、命令序号及回显。

- EtherNet/IP：以 PLC 视角明确 Produced/Consumed 或 Input/Output Assembly 方向、RPI、连接状态、超时和字节序。
- 离散 I/O：物理 X/Y 只在映射层出现，记录常态、有效电平、断线状态和滤波时间。
- 网络命令优先使用“请求保持到确认”或“命令序号+回显”，不要依赖单扫描脉冲。
- 通信中的 `SafetyOK` 只能用于普通状态监视，不能替代急停、门锁、STO 或安全 PLC。

## 6. CANopen 与轴

- 通用 CANopen 按 CiA 301 管理 NMT、Boot-up、Heartbeat、PDO、SDO、EMCY、节点号和波特率。
- 只有设备 EDS/手册声明 CiA 402 时，才使用其驱动状态机和对象，如 Controlword `6040h`、Statusword `6041h`、Modes `6060h/6061h`、目标/实际位置 `607Ah/6064h`、错误码 `603Fh`。
- 每个节点记录 EDS 版本、PDO 映射、传输类型、Heartbeat 超时、EMCY 处理、重连和失效状态。
- 脉冲轴记录脉冲/方向通道、ServoOn、Reset、Home、正负限位、Ready、Alarm、InPosition、单位比例、速度/加减速和停止行为。
- 运动接口必须有单一轴状态机所有者；HMI 只能提出请求，不能直接写脉冲输出或驱动控制字。

## 7. 报警与 HMI

- 报警表至少含报警 ID、活动位、锁存位、级别、来源、触发条件、复位条件、HMI 文本、设备、响应和责任人。
- `Active` 表示当前条件，`Latched` 保存事件，`Ack` 表示已确认，`ResetReq` 只是请求；四者不可混为一个位。
- HMI 手动命令必须经过模式、权限、互锁和设备状态校验；禁止 HMI 直接写 Y 地址。
- 点动采用按住有效、松开停止，并定义通信中断的停止行为；远程脉冲按钮使用请求/确认或 PLC 边沿捕获。

## 7.1 上下站联机

- 支持“前站主动出料、后站接收”和“后站主动取料、前站释放定位”两类标准握手，具体信号见 `templates/common/station-handshake-template.md`。
- 联机信号采用保持到确认或命令序号/回显，不使用无法保证捕获的单扫描脉冲。
- 本机暂停时仍采集并锁存对方交互信号；进入实际轴、阀动作或脉冲步骤前必须重新检查本机运行中条件。
- X/L 地址、N24、PE和8芯连接器针脚只在项目接线映射中确定，不写死在通用顺控。

## 8. 发布门禁

1. 地址无重复且范围未与 HWCONFIG/保持区/通信表冲突。
2. 每个物理输出、命令字和轴控制字只有一个写入者。
3. 方向、数据类型、字节/字序、比例、单位和失效值完整。
4. 断网、超时、PLC STOP、机器人掉线、驱动报警和重上电行为已测试。
5. ISPSoft 编译通过，离线测试完成，现场调试按 `safety-boundaries.md` 执行。
