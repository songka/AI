# 版本发布与回滚说明

## 1. 当前基线

- Skill：`delta-as228t-plc`
- 范围：Delta AS228T-A + ISPSoft 3.19+ + ST
- 当前版本：3.0.0
- 当前包：`delta-as228t-plc-3.0.0.zip`
- SHA-256：`FAA76A40FF740AB9B87D884317CE826965E5F99380AD6CE5E181AF8A22747B8E`

## 2. 建议目标版本

模拟自测属于新增工作流、模板和评测能力，按现有语义化规则建议升级为 `3.1.0`。

若实施中改变安全边界、确认触发方式或进行不兼容目录重组，应停止发布并重新评估是否升级主版本，不得仍按 3.1.0 发布。

## 3. 发布前检查

1. `package/VERSION` 为 3.1.0。
2. `SKILL.md`、模拟参考、模板、评测和索引内部链接有效。
3. 全文搜索无 DVP、AH、WPLSoft 和其他 PLC 污染。
4. 无脚本、可执行文件、隐藏自动联网或在线 PLC 控制。
5. ISPSoft 实测结论与限制说明一致。
6. 官方 Skill 校验通过。
7. 发布包内容来自已经验证的准确源码状态。

## 4. 发布产物

- `releases/delta-as228t-plc-3.1.0.zip`
- `package.zip`：与 3.1.0 发布包字节一致。
- `release-manifest.json`：新增 3.1.0 current，3.0.0 改为 rollback。
- `RELEASES.md`：记录新增模拟工作流、模板、评测、实测范围和已知限制。
- SHA-256：分别核对版本包与 `package.zip`，两者应一致。

## 5. 回滚

出现以下情况之一时回滚至 3.0.0：

- 新版破坏 G0～G7 门禁。
- 模拟模式可能驱动真实输出。
- 错误宣称模拟器验证了现场运动、通信或安全功能。
- 模板导致 D100～D199 或 D24000～D29999 被错误占用。
- Skill 校验、内部链接或核心评测失败。

回滚操作只替换分发包和 manifest current 指向，不删除 3.1.0 故障包和证据；应将故障包标记为 withdrawn 并记录原因。

## 6. 版本记录要求

发布记录至少包含：

- 版本、日期、实施人、复核人。
- 变更文件。
- 官方资料基线。
- ISPSoft 版本和模拟器驱动类型。
- 通过用例数、失败用例数、未验证现场项。
- 发布包 SHA-256。
- 回滚版本和回滚条件。
