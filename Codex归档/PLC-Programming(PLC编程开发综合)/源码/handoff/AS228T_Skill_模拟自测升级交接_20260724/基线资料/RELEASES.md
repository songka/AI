# Delta AS228T-A Skill 发布记录

## 3.0.0 — 2026-07-23

- Skill范围收窄为仅AS228T-A、ISPSoft 3.19及以上、ST；裸写AS228T按AS228T-A处理。
- PLC型号、ISPSoft基线、固件和语言改为固定默认，不再作为常规确认问题；固件仅在官方明确限制某项特定功能时作为阻塞事实提出。
- 新增功能块接口固定模板：每个FB默认先有自动状态和状态运行中。
- 输入顺序固定为程序状态、伺服状态、感应器状态、设置类。
- 输出顺序固定为流程号、状态、报警、伺服驱动、气缸动作、联机交互；局部变量最后。
- 同步更新确认流程、编程规范、平台参考、评测和流程索引。

## 2.3.0 — 2026-07-23

- 新增G0～G7强制确认门禁：需求、I/O、结构、流程、报警/接口、变量交付格式和最终生成授权逐项确认。
- 每个确认阶段必须生成确认文件；上游内容变更时，受影响的下游确认文件作废并重新确认。
- 最终授权前禁止一次性生成完整ST或可导入变量CSV。
- 最终交付固定包含`全局变量.csv`、`局部变量.csv`和按确认POU拆分的ST文件。
- 固化变量顺序：输入、输出、共享/接口数据、局部；POU内部按`VAR_INPUT`、`VAR_OUTPUT`、`VAR`排列。
- 优先复用当前ISPSoft导出的CSV格式；无样例时仅生成待导入复核的UTF-8评审CSV，不虚报兼容性。

## 2.2.0 — 2026-07-23

- 固化整机程序框架：主控、自动流程、报警、HMI手动、设备模块和最终输出映射。
- 增加阀专用驱动模板；动作逻辑不直接写普通阀报警，只有有限重试耗尽才产生诊断事件。
- 固化步骤号规则：非自动为-1，0～99用于复位/准备，生产步骤从100开始并按10递增，输出集中在末尾计算。
- 修订暂停/恢复：轴输出不保持，阀逻辑状态按步骤保持；联机信号在本机暂停时仍捕获。
- 增加“前站主动出料”和“后站主动取料/请求释放”两种上下站握手模板。
- 将I/O地址参考同步到v0.4固定分区，包括D100～D199伺服缓存、20轴接口和CANopen自动映像保护区。
- 增加相应行为评测；安全边界未放宽。
