# 任务交底书

## 1. 任务名称

Delta AS228T-A PLC Skill：程序生成后模拟自测、故障注入及现场异常验证能力升级。

## 2. 背景

当前 Skill 3.0.0 已规定先确认需求、I/O、结构、流程、报警、接口和交付格式，再生成全局变量 CSV、局部变量 CSV 和 ST 程序。现在需要把“生成后如何自测”固化为标准流程，使接手工程师能够验证正常流程、暂停恢复、报警、通信异常和现场常见故障。

## 3. 固定范围

- PLC：仅 Delta `AS228T-A`。
- 编程软件：`ISPSoft 3.19+`。
- 语言：仅 `ST`。
- 运动方式：通用 CANopen（可采用 CiA 402 的前提是 EDS/设备手册明确支持）或脉冲轴。
- 机器人交互：EtherNet/IP 或离散 I/O。
- 最大轴数：20。
- 不纳入：DVP、AH、WPLSoft、其他 PLC、其他语言、绕过安全回路。

## 4. 任务目标

1. 在不改变 G0～G7 确认规则的前提下，增加生成后的 G8 软件自测和 G9 现场验证。
2. 建立可复用的模拟输入层、故障注入接口和自动判定机制。
3. 形成正常、边界、故障、恢复四类测试用例。
4. 明确模拟器可以证明和不能证明的事项。
5. 使用 ISPSoft 3.19+ 的 AS200 Simulator 对示例 ST 工程完成编译、下载、RUN、监视和结果记录。
6. 完成 Skill 版本升级、评测补充、发布包、校验值和回滚记录。

## 5. 实施原则

- 仿真层与真实 I/O 映射层隔离，测试代码不得直接驱动现场输出。
- 每个测试用例必须有初始条件、注入动作、预期时间、预期步骤、预期输出、预期报警、复位条件和判定结果。
- 软件模拟通过不等于现场安全通过。
- 真实 CANopen、EtherNet/IP、脉冲、高速 I/O、STO、接线极性和机械动作必须在受控硬件验证。
- 任何新增规则不得静默放宽现有安全要求。

## 6. 接手人需要优先确认的缺口

- ISPSoft 3.19+ 实际导出的全局/局部变量 CSV 格式样例。
- AS200 Simulator 对本项目所用 ST 语法、定时器、功能块和数据类型的实际支持情况。
- 现场具体伺服型号、机器人型号、I/O 模块和安全回路图。
- 现场对故障响应时间、暂停行为、掉电保持和恢复策略的项目级要求。
- D100～D199 缓存与 D20000～D20799 永久参数之间的加载、应用、保存规则是否已由项目负责人确认。

## 7. 完成定义

只有以下事项全部完成，任务才可关闭：

- 新增模拟工作流、模板、评测和索引。
- 示例工程在 ISPSoft 3.19+ 编译通过。
- AS200 Simulator 中正常流程和规定的软件故障用例通过。
- 形成测试结果和限制说明。
- Skill 校验通过，发布 3.1.0，保留 3.0.0 回滚包。
- 现场验证项目明确标为“已验证”或“待现场”，不得空白或模糊表述。

## 8. 不属于本任务的默认授权

本任务不授权在线下载到生产 PLC、不授权强制输出、不授权屏蔽急停/门锁/STO、不授权修改现场保持区、不授权更换 PLC 或编程语言。
