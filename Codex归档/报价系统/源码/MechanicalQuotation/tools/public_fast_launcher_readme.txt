机械报价系统——公共槽快速启动说明

1. 将本文件夹完整放到 SMB 公共槽，用户不要打开或解压 MechanicalQuotation_payload.zip。
2. 每位用户直接双击“快速启动器.bat”。
3. 首次使用或版本更新时，启动器会把一个压缩载荷复制到该用户的本机目录并解压；之后直接使用本机副本，启动更快。
4. 不同 Windows 用户使用各自的本机缓存、日志、临时文件和导出目录，可以同时运行，互不覆盖。
5. 同一用户连续重复点击时，启动器会等待当前复制完成，避免两个进程同时更新本机副本。
6. 公共槽文件夹只需读取权限；发布新版本时，请整体替换本文件夹，避免只替换其中一个文件。
7. 本轻量版不支持 PDF。
