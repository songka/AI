# 供应商价格审核与正式发布

## 适用范围

供应商管理页面录入或导入的报价属于原始来源价格（S），初始状态为“待审核”。这些记录不会直接参与
正式报价。只有管理员在“价格审核”页面批准后生成的公司价格（C），才会进入已发布价格表。

## 操作流程

1. 工程师在“供应商管理”中新增报价或导入供应商报价 Excel。
2. 管理员登录后打开“价格审核”，筛选“待审核”。
3. 查看原始单价、计价单位、税价口径和生效日期；报价单号、来源文件如有则一并展示。
4. 资料不完整时点击“驳回”，填写中文原因；正式价格版本不会改变。
5. 资料正确时点击“批准并发布”，填写审核意见并再次确认。
6. 系统生成不可修改的新价格快照、归档旧版本指针、切换当前版本并刷新本地缓存。

原始供应商记录和审核结果均采用追加保存，不允许事后覆盖。需要修正时，应新增一笔供应商报价后
重新审核，不得改写旧记录。

## 发布前阻挡条件

- 价格为空、为零或负数。
- 缺少明确计价单位。
- 缺少生效日期，或日期不是 `YYYY-MM-DD`。
- 失效日期早于生效日期。
- 币种不是人民币；系统不会自动猜测汇率。
- 含税价格没有明确税率。
- 来源记录不是“待审核”，或已经批准/驳回。
- 管理员看到的正式版本已被另一位管理员更新。

含税供应商报价会按记录中的税率换算成未税公司价；正式记录固定标记为
`price_basis=EXCLUDING_TAX`。系统不会把未知价格保存为零。

## 权限与并发

- 录入供应商报价需要“修改价格”权限。
- 查看与处理价格审核需要“审核发布”权限，目前仅管理员角色拥有。
- 发布使用 5 分钟 SMB 独占锁和当前版本校验，避免两位管理员同时覆盖版本指针。
- 每次批准或驳回都会在 `audit/` 留下独立审计文件，包含操作者、时间、来源哈希和发布版本。

供应商报价单号和来源文件均为可选项。即使二者为空，系统仍以供应商编号、价格记录编号、
录入人、录入时间及完整记录哈希保证追溯性。

## API

- `GET /api/v1/admin/price-approvals`：查询审核记录，可传 `status` 和 `query`。
- `POST /api/v1/admin/price-approvals/{supplier_id}/{price_record_id}/approve`：批准并发布。
- `POST /api/v1/admin/price-approvals/{supplier_id}/{price_record_id}/reject`：驳回。

批准接口可传 `expected_current_version`。版本不一致时返回冲突，客户端必须刷新后重新确认。

## SMB 文件

- 原始报价：`suppliers/prices/{supplier_id}/PR-*.json`
- 审核结果：`change-requests/price-reviews/RV-PR-*.json`
- 正式快照：`prices/published/company-pricebook-*-snapshot.json`
- 当前版本：`prices/published/current-version-pointer.json`
- 旧指针归档：`prices/archive/pointer-*.json`
- 审计记录：`audit/AUD-PRICE-*.json`

禁止直接在共享盘编辑正式快照或版本指针；应始终从应用的价格审核页面发布。
