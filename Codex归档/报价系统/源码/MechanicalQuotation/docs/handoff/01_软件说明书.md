# 软件说明书

## 用途

系统读取 DXF/DWG/部分 SolidWorks 图纸及报价资料，提取特征、判断零件类别与工艺、按公司价格表生成分项报价，并提供 AI 辅助理解、工艺建议、待确认项估价和价格审核。正式金额仍按材料、加工、表面处理及其他费用逐项计算。

## 当前报价流程

1. 图纸与备注理解：AI 优先，失败时回退内置规则。
2. 零件类别分类：加工件、钣金件、焊接件、型材组装件。
3. 特征提取、材料判断：确定性规则为主。
4. 工艺路线：AI 建议与规则校验结合，支持车、铣、磨、钳工、放电、线切割、激光、折弯、焊接和表面处理。
5. 工时与分项计价：正式价格表和规则为主；AI 工时需通过合理性校验。
6. 报价汇总、价格审核、人工复核建议。

步骤 1、2 使用全局路由；步骤 3–11 可按零件类别路由；步骤 6、7、10、11 可进一步按具体工艺路由。多工艺零件可在同一步调用多个工艺 Skill/Agent，结果按工艺保留后合并。

## 数据与安全

- DeepSeek Key 只存放在运行目录 `runtime/secrets/deepseek_api_key.txt`，不写入普通设置、源代码或交付清单。
- Key 默认不存在；未配置时 AI 步骤显示告警并回退内置规则。
- 报价历史使用 SQLite，数据库地址可设置为本机目录/文件或公共共享目录/文件。
- 登录与权限控制默认关闭；启用后才需要建立管理员和本机加密口令。
- 外接 Skill/Agent 支持内置、文件夹或 HTTP 资源；发布到公共槽前需管理员确认。

## 支持与限制

- 支持：DXF 直接读取；DWG 经外部 ODA 转换；SLDDRW/SLDPRT 依赖本机可用的 SolidWorks；Excel 读、写、修改和导出命令；Python、EXE、CLI、批处理 Skill 命令。
- 不支持：PDF 图纸识别与报价，相关组件已从轻量包移除。
- AI 输出属于辅助证据。正式价格、异常重量、工时、缺失材料、低置信度分类和审核 `REVIEW` 必须人工确认。
- 公共 SQLite 适合中小规模内部并发；网络断开或大量同时写入时应暂停保存并由管理员检查数据库。若并发量持续增大，后续应迁移到专用数据库服务。
