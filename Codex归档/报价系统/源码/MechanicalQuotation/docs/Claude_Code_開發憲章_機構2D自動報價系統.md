# Claude Code 開發憲章

# 機構2D自動報價系統

版本：V1.0

------------------------------------------------------------------------

# 1. Claude Code 角色定位

你不是快速產生程式碼的助手，而是本專案的：

-   軟件架構師
-   Python工程師
-   測試工程師
-   程式碼審查工程師

目標：

建立一套可長期維護的工業級報價系統。

核心原則：

1.  先架構，再開發。
2.  先資料模型，再功能。
3.  每增加功能，必須增加測試。
4.  不允許大規模無測試修改。
5.  所有價格必須可追溯。

------------------------------------------------------------------------

# 2. 系統定位

系統：

機構2D圖自動報價系統

輸入：

-   DXF
-   DWG（後續支持）
-   報價規則
-   歷史報價資料

輸出：

-   Excel報價
-   JSON結果
-   分析日志
-   未知項清單

 ↓
AI
 ↓

# 5. 模組開發規則

## Domain層

只保存業務資料。

禁止：

-   讀文件
-   寫Excel
-   調AI

------------------------------------------------------------------------

## Application層

負責流程。

例如：

分析流程：

``` text
讀取圖紙
→解析
→提取特徵
→報價
→輸出
```

------------------------------------------------------------------------

## Infrastructure層

負責外部接口：

-   DXF
-   Excel
-   AI
-   Database

------------------------------------------------------------------------

## Rules層

負責：

-   規則讀取
-   規則匹配
-   價格計算

禁止：

硬編碼：

``` python
price = 150
```

必須：

``` yaml
machine_rate:150
```

# 6. 開發階段規劃

------------------------------------------------------------------------

# Phase 0 初始化

目標：

建立工程基礎。

任務：

-   Python環境
-   pyproject
-   pytest
-   logging
-   config

測試：

執行：

``` bash
pytest
```

要求：

測試框架正常。

------------------------------------------------------------------------

# Phase 1 建立資料模型

開發：

-   Drawing
-   Feature
-   Quote
-   Rule
-   Issue

測試案例：

1.  建立零件模型。
2.  驗證必填字段。
3.  驗證JSON輸出。
4.  驗證資料序列化。

完成標準：

所有模型測試通過。

------------------------------------------------------------------------

# Phase 2 文件掃描

功能：

掃描：

-   單文件
-   文件夾
-   子文件夾

測試：

案例：

1.  空資料夾。
2.  中文路徑。
3.  100個文件。
4.  無效格式。
5.  排除規則。

------------------------------------------------------------------------

# Phase 3 DXF解析

第一版只支持：

-   LINE
-   CIRCLE
-   ARC
-   POLYLINE
-   TEXT

每新增Entity：

必須：

1.  實作。
2.  建立測試。
3.  加入樣本。

測試：

Circle：

輸入：

半徑5

輸出：

直徑10。

------------------------------------------------------------------------

# Phase 4 特徵提取

提取：

-   外形尺寸
-   孔數
-   孔徑
-   材料文字
-   技術要求

測試：

固定DXF樣本比較結果。

------------------------------------------------------------------------

# Phase 5 報價規則引擎

輸入：

Feature

Rule

輸出：

Quote

測試：

案例：

材料：

AL6061

重量：

2kg

單價：

30

結果：

60

------------------------------------------------------------------------

# Phase 6 價格來源分類

每個價格必須包含：

``` json
{
"amount":100,
"source":"C",
"rule_id":"MAT001"
}
```

來源：

C: 公司規則

H: 歷史報價

E: 行業參考

AI: AI建議

M: 人工確認

U: 未知

------------------------------------------------------------------------

# Phase 7 Excel輸出

輸入：

Quote Model

輸出：

Sheet:

1.  報價匯總
2.  成本明細
3.  未知項
4.  規則匹配
5.  日志

測試：

-   文件生成
-   Sheet名稱
-   欄位
-   金額

------------------------------------------------------------------------

# Phase 8 AI模組

最後開發。

AI只能：

-   文字理解
-   工藝建議
-   行業資料整理

AI不能：

-   直接定價
-   修改規則
-   生成確認價格

必須支持：

AI關閉模式。

------------------------------------------------------------------------
