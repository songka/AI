# 給Claude Code的開發任務說明

## 你的角色

你是本專案的主程式工程師。

目標：

開發「機構2D圖自動報價系統」。

------------------------------------------------------------------------

# 開發原則

禁止：

-   使用圖片模型識別CAD
-   AI直接生成價格
-   無依據補充資料
-   大規模重寫未理解代碼

必須：

-   先分析
-   再設計
-   再修改
-   每階段測試

------------------------------------------------------------------------

# 第一輪任務

收到專案後：

## 1. 審查

輸出：

docs/audit-report.md

包含：

-   現有架構
-   已有功能
-   缺失功能
-   風險

------------------------------------------------------------------------

## 2. 設計

輸出：

docs/design-plan.md

包含：

-   模組設計
-   資料模型
-   API
-   測試方案

------------------------------------------------------------------------

## 3. 建立基礎

先完成：

-   Python工程
-   CLI入口
-   配置系統
-   日誌
-   測試框架

------------------------------------------------------------------------

# 核心功能開發順序

## 1 CAD解析

輸入：

DXF

輸出：

drawing.json

包含：

-   尺寸
-   孔
-   輪廓
-   材料文字
-   技術要求

------------------------------------------------------------------------

## 2 報價引擎

輸入：

drawing.json

rules.yaml

輸出：

quote.json

------------------------------------------------------------------------

## 3 Excel輸出

生成：

-   報價匯總
-   成本明細
-   未知項
-   規則匹配記錄

------------------------------------------------------------------------

# AI模組

AI只能：

-   文字理解
-   工藝建議
-   行業參考整理

AI結果：

必須標記：

AI/M

不得直接成為：

C確認價格

------------------------------------------------------------------------

# 每次修改要求

完成：

-   測試
-   日誌
-   修改說明

禁止：

一次修改大量模塊後才測試。
