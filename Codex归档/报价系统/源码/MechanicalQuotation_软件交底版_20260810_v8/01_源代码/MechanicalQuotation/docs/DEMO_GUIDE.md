# 機械加工件智能報價系統 — 展示指南

## 快速啟動

### 啟動桌面 UI
```bash
.venv\Scripts\python -m quotation.ui.demo_app
```

### 啟動 REST API
```bash
.venv\Scripts\python -m uvicorn quotation.api.main:app --host 127.0.0.1 --port 8000
```
Swagger: http://127.0.0.1:8000/docs

### 一鍵啟動（可攜式目錄）
```bash
cd dist\MechanicalQuotation
start_ui.bat
```

桌面報價只需啟動 `MechanicalQuotation.exe` 或 `start_ui.bat`，不需要 FastAPI。
只有外部系統以 API 對接或需要 Swagger 調試時，才另行執行 `start_api.bat`，然後開啟
http://127.0.0.1:8000/docs。

## 主要功能

### 1. 新建報價
- 點擊「載入J003範例」或「載入W001範例」體驗完整報價流程
- 點擊「選擇圖紙」載入外部 DXF/DWG/PDF 文件
- 點擊「選擇資料夾」批量掃描圖紙並自動配對
- 報價明細表顯示所有成本項目和價格來源
- 點擊報價項目查看「價格來源詳情」（公司價格ID、供應商來源等）
- 底部顯示未稅小計、稅率17%、稅額、含稅總價

### 2. 外部圖紙批量報價
- 支持 DXF、DWG、PDF 格式
- 自動尋找同圖號的配對文件
- 支持中文路徑、空格、子資料夾
- 單文件失敗不影響整批
- 批量進度條顯示處理狀態

### 3. 報價記錄
- 所有報價自動保存到本機 SQLite 資料庫
- 支援按圖號、文件名、狀態、日期搜尋
- 可查看歷史報價明細和價格來源
- 可重新匯出 Excel

### 4. 價格管理（唯讀）
- 查看已發布公司價格表
- 查詢材料、加工、表面處理價格
- 查看供應商原始報價記錄

### 5. 人工審核
- 對「待確認」項目補充材料、厚度、加工方式等
- 重新計算報價後保留原始版本
- 人工價格來源標記為「人工確認價格」
- 審核記錄完整保存

### 6. 匯出 Excel
- 單件報價 Excel
- 批量報價彙總 Excel（含報價總覽、明細、待確認、原始文件、價格追溯）

## 常見問題

| 問題 | 解決方法 |
|------|----------|
| AI 顯示未配置 | 執行 `tools/prepare_runtime_secrets.py --source <key文件>` |
| 文件解析失敗 | 確認文件為有效 DXF 格式；DWG 需先轉換為 DXF |
| API 無法啟動 | 確認端口 8000 未被佔用 |
| Excel 匯出失敗 | 確認 runtime/exports/ 目錄存在 |
