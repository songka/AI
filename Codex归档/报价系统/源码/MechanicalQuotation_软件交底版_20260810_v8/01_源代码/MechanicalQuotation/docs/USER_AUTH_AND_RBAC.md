# 用户登录、权限与多电脑接入说明

版本：1.3（2026-08-06）

## 0. 默认免登录

桌面程序无论是否已经建立用户库，启动时都直接进入免登录主画面，不弹出强制登录窗口。访客可使用
新建报价、批量报价、报价记录、Excel 导出和只读价格管理。需要供应商维护、价格审核、用户管理、
外接 Skill 设置或系统设置时，从左侧“管理员登录”进入；登录成功后同一窗口立即按账号权限增加菜单，
不需要重启。登录账户可随时选择“退出登录”回到免登录模式。

免登录模式不会显示供应商管理、价格审核、用户管理、外接 Skill 设置和系统设置。报价记录删除也只
对具有 `quotation.delete` 权限的登录账户显示。FastAPI 仍按系统设置中的认证开关执行接口权限验证。

## 1. 首次建立管理员

首次点击“管理员登录”时，如果 SMB 公共槽与本地缓存都没有 `data/users.json`，系统会显示“建立首位管理员”。管理员自行输入用户名、显示名称、管理员登录密码及用户库加密口令。登录密码至少 8 位并同时含字母和数字；加密口令至少 16 个字符。建立成功后系统会直接完成首次登录，不再要求重复输入一次密码。

系统不生成默认账号或默认密码。用户库加密口令与登录密码用途不同：前者用于解密整份公共用户资料，后者只用于个人登录。

如果首位管理员建立后从未成功登录，登录失败提示后可选择“恢复首位管理员”，输入原用户库加密
口令并重新设置管理员登录密码。该入口只适用于唯一且从未登录过的首位管理员；成功登录一次后即
永久关闭，后续密码重置必须由已登录管理员执行。

## 2. 资料保存位置

- SMB 主用户库：`SMB公共槽/data/users.json`；
- 本地加密缓存：`runtime/cache/smb/data/users.json`；
- 本机用户库口令：`runtime/secrets/user_store_key.txt`；
- 环境变量替代方式：`MECHANICAL_QUOTATION_USER_STORE_KEY`。

`users.json` 使用 AES-GCM 整包加密，用户名和 bcrypt 密码摘要都不会以明文出现。登录密码使用 bcrypt 成本因子 12。`runtime/secrets/*` 已被 Git 忽略，不得加入提交或复制到公共槽。

## 3. 其他电脑接入

其他电脑第一次启动时，如发现公共用户库但本机没有口令，会显示“连接公共用户库”。输入与首台电脑相同的用户库加密口令并验证成功后，口令只保存到该电脑的本机侧车文件。

SMB 在线时以公共用户库为准并刷新加密缓存；SMB 临时离线时可以使用最后一次缓存登录。用户新增、停用、密码重置等管理操作应在 SMB 在线时完成，避免多台电脑离线修改造成版本覆盖。

## 4. 登录安全规则

- 连续 5 次密码错误后锁定 30 分钟；
- 桌面会话空闲 30 分钟锁定，绝对有效期 8 小时；
- 管理员重置密码后，用户下次登录必须修改密码；
- 新密码不能与最近 3 次密码相同；
- 系统禁止停用最后一名有效管理员；
- API 会话使用内存令牌，程序关闭后全部失效，不写入磁盘。

## 5. 角色权限

| 角色 | 主要能力 |
|---|---|
| 管理员 | 全部报价、成本、规则、价格、用户、审核、审计和系统设置 |
| 工程师 | 报价、成本查看、导出、规则修改申请、价格维护 |
| 业务 | 建立、查看及导出报价，不查看成本，不维护价格 |
| 查看者 | 只查看报价 |

管理员登录后可进入“用户管理”，新增用户、重置临时密码、启用或停用账号，并为每个用户选择角色及逐项勾选功能权限。角色只负责提供一组默认权限；管理员保存逐项权限后，以该用户的单独授权为准。旧版用户资料没有单独授权字段时继续沿用原角色默认权限，不需要迁移。

登录模式启用时，桌面左侧菜单按用户的实际权限隐藏无权功能；页内的导出、人工审核、供应商维护和价格发布按钮也执行相同控制。权限修改后，该用户重新登录即可刷新桌面菜单。FastAPI 对报价、导出、人工审核、价格查询、SMB 同步及用户管理执行同一套 RBAC，并在每次请求时重新读取当前用户状态和权限，因此停用或撤权会立即影响已有 API 令牌；未登录返回 401，无权限返回 403。

每次保存报价记录时同时记录业务报价人（登录账号显示名称；未登录为“免登录用户”）、当前 Windows
登录用户名、电脑名称和本机解析到的 IP 地址。管理员可把 `quotation.delete` 单独分配给用户；删除
报价时会一并删除该报价的费用明细、人工调整和审核记录。

为避免管理员把自己锁在系统外，当前登录管理员不能修改自己的角色/权限，也不能停用自己；相关操作应由另一名管理员执行。系统仍禁止停用或降级最后一名有效管理员。

## 6. FastAPI 登录接口

- `GET /api/v1/auth/status`：只返回配置状态，不返回路径、用户或口令；
- `POST /api/v1/auth/login`：用户名和密码登录；
- `GET /api/v1/auth/me`：用 `Authorization: Bearer <令牌>` 查询当前用户；
- `POST /api/v1/auth/logout`：退出并销毁内存会话。

用户管理接口：

- `GET /api/v1/admin/users`：查看用户及中文权限名称，需要 `user.view`；
- `POST /api/v1/admin/users`：新增用户并分配角色/权限，需要 `user.manage`；
- `PATCH /api/v1/admin/users/{user_id}/access`：修改角色与逐项权限；
- `POST /api/v1/admin/users/{user_id}/reset-password`：设置临时密码；
- `PATCH /api/v1/admin/users/{user_id}/status`：启用、停用或锁定账号。

公共用户库尚未建立时处于首次安装模式，便于完成健康检查和初始化。只有系统设置中的登录模式
已经启用时，受保护接口才要求登录。
