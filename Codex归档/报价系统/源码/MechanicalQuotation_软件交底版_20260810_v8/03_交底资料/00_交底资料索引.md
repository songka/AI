# 机械加工件智能报价系统软件交底资料

交底版本：2026-08-10 V8（源代码版本 0.2.0）

## 交付结论

本交底包包含可执行程序、完整可维护源代码、配置模板、Skill/Agent 改写工具、样例和验收资料。交付包默认不含 DeepSeek Key、不含用户库加密口令、不含报价历史数据库，也不启用账号登录。

## 阅读顺序

1. `01_软件说明书.md`：系统用途、流程、边界。
2. `02_部署与快速启动.md`：本机与公共槽部署。
3. `03_Key与数据库配置.md`：独立 Key 和统一数据库地址设置。
4. `04_多人公共槽使用说明.md`：多人使用与互不干扰原则。
5. `05_Skill与Agent开发改写指南.md`：改写、新建、拆分、合并和验收。
6. `06_运维与故障排查.md`：常见问题和恢复方法。
7. `07_验收清单.md`：接收方逐项确认。

## 目录说明

| 目录 | 内容 |
|---|---|
| `01_源代码` | 程序、测试、协议、样例和构建工具；不含开发缓存、历史交付包和密钥 |
| `02_可执行程序` | 可直接复制到本机运行的轻量程序和快速启动器 |
| `03_交底资料` | 本套交底文档 |
| `04_Skill与Agent工具` | 引导式改写/新建工具及其引用资料 |
