# 运维与故障排查

| 现象 | 先检查 | 处理 |
|---|---|---|
| 打开很慢 | 是否直接从公共槽运行 EXE | 改用快速启动器，等待首次复制；后续从本机缓存启动 |
| 提示缺 Key | 系统设置中的 AI 状态 | 从 Key 文本文件单独设置；不使用 AI 时允许规则回退 |
| 数据库打不开 | 数据库地址、共享权限、网络 | 修正地址后重启；不要删除公共数据库旁的临时日志文件 |
| 第一次打开要求密码 | 是否启用了登录模式 | 默认关闭；管理员可在系统设置取消勾选 |
| DWG 无法识别 | ODA 路径和授权 | 合法安装 ODA File Converter 后在系统设置选择 EXE；DXF 不需要 |
| PDF 无法识别 | 当前版本能力边界 | 当前轻量版不支持 PDF，请提供 DXF/DWG/受支持的 SolidWorks 文件 |
| AI 超时/无效 JSON | 网络、Key、服务状态 | 程序告警并回退规则；保留人工审核，不连续无限重试 |
| 外接 Skill ID 不一致 | manifest 与运行输出 | 文件夹资源可规范化并告警；HTTP 资源必须修正为完全一致 |
| 批量详情打不开 | 是否为本交底版、记录是否完整 | 重新启动本版并复测；保留错误文字和对应图号交给维护人员 |

发生异常时保留：软件版本、时间、图号、输入文件类型、数据库地址类型（本机/公共，不含密码）、错误全文和 `runtime/reports`。不得在故障资料中附 Key、正式价格表或敏感图纸，除非使用获授权的内部渠道。
