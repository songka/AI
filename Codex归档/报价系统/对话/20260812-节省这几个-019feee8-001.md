## 助手

这些菜单的作用：

- **置顶聊天**：固定在聊天列表顶部。
- **重命名聊天**：修改当前聊天名称。
- **归档聊天**：从常用列表中收起，但不会删除。
- **标记为未读**：添加未读标记，方便稍后处理。
- **在资源管理器中打开**：打开当前项目所在文件夹。
- **复制工作目录**：复制当前项目的本地路径。
- **复制会话 ID**：复制当前聊天的唯一编号，常用于定位或排查问题。
- **复制深度链接**：复制一个可直接打开当前聊天的 Codex 链接。
- **在新聊天中继续**：基于当前上下文创建一个新聊天，仍使用当前工作目录。
- **在新工作树中继续**：创建新的 Git worktree 和聊天，适合并行开发，避免修改互相干扰。
- **在新窗口中打开**：把当前聊天放到单独的 Codex 窗口中。

最容易混淆的是最后三个：**新聊天**是分支讨论，**新工作树**是隔离代码开发，**新窗口**只是改变显示窗口。
