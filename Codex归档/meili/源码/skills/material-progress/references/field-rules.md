# 字段与判定口径

仅在分析物料数据、映射表头或解释计算口径时读取本文件。

## 常见字段映射

| 标准字段 | 常见别名 |
| --- | --- |
| 项目/订单 | 项目、项目号、订单号、工单、PO、采购订单 |
| 物料编码 | 料号、物料号、零件号、Part No、PN、SKU |
| 物料名称 | 品名、名称、描述、规格描述 |
| 批次 | 批号、Lot、交付批次、阶段 |
| 需求数量 | 需求数、计划数量、订单数量、应交数量、Qty |
| 已完成数量 | 完成数、已交数量、累计交付、合格数量、入库数量 |
| 未完成数量 | 欠数、欠料数量、未交数量、Open Qty、Backlog |
| 需求日期 | 要求日期、需用日期、交期、计划到货日、Need Date |
| 承诺日期 | 回复交期、供应商承诺日、Promise Date、ETA |
| 预计完成日 | 预计到货、预计交付、预计完成、Forecast Date |
| 当前状态 | 状态、采购状态、生产状态、交付状态、Progress |
| 责任人 | Owner、采购员、跟单人、负责人 |
| 更新时间 | 最后更新、数据日期、反馈日期、Updated At |

字段名称相同但业务含义不明确时，结合值域、单位和相邻字段判断，并在输出中注明假设。

## 标准状态

按业务事实映射为以下状态，保留原状态供追溯：

| 标准状态 | 典型原状态 |
| --- | --- |
| 未开始 | 未下单、待采购、待启动、Open |
| 采购中 | 已询价、已下单、供应商备料 |
| 生产中 | 排产、加工中、组装中 |
| 待发运 | 生产完成、待提货、待出库 |
| 运输中 | 已发货、在途、已提货 |
| 已到货 | 已签收、到厂、收货待检 |
| 检验中 | IQC、待检、复检、质量确认 |
| 已完成 | 合格入库、齐套、交付完成、Closed |
| 阻塞 | 缺料、停产、质量异常、供应商异常、Hold |
| 已取消 | 取消、作废、无需采购 |

“已发货”不等于“已到货”，“已到货”不等于“已完成”；只有达到用户定义的终点或合格入库且数量满足需求时才判定完成。

## 日期规则

- 解析 Excel 序列日期、ISO 日期、中文日期和含时区时间戳，统一展示为 `YYYY-MM-DD`。
- 缺少年份时不要擅自跨年；结合统计时点推断后必须注明。
- 同时存在需求日期和承诺日期时，需求日期用于判断业务逾期，承诺日期用于判断供应商失约；两者分别报告。
- 预计日期早于最新更新时间或明显早于当前状态时，标记为“预测日期失效”。

## 严重级别

- **高**：已阻塞、已逾期、关键件短缺、预计日期晚于需求日期，或会直接影响里程碑。
- **中**：3 天内到期仍未完成、责任人缺失、承诺日期未确认、预测日期可能失效。
- **低**：非关键字段缺失、轻微格式问题或尚未影响交付的异常。

用户提供关键件清单、项目优先级或自定义 SLA 时，优先采用用户规则并记录覆盖项。
