## 助手

可以。我能模擬多個 Agent 分工、互相討論，再由主 Agent 彙整結論。

例如：

**主 Agent：** 請大家評估「是否該使用 React 開發這個網站」。

**研究 Agent：** React 生態成熟、元件豐富，適合大型互動介面。

**效能 Agent：** React 效能通常足夠，但需要注意套件大小與重新渲染。

**維護 Agent：** 團隊若熟悉 JavaScript，React 的長期維護成本較低。

**反對 Agent：** 如果網站很簡單，使用原生 HTML/CSS/JavaScript 可能更輕量。

**主 Agent：** 綜合意見：若是大型互動網站，建議使用 React；若是簡單展示頁，原生方案更合適。

也可以進一步讓不同 Agent 扮演程式設計師、測試員、產品經理，並進行多輪對話。
