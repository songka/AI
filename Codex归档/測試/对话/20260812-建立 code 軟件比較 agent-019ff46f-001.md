## 助手

這通常不是 OpenCode 本身問題，而是 `newapi-codex-manager-chatgpt5.6-luna` 的模型配置沒有宣告或實際支援圖片輸入。

請檢查以下幾點：

1. 模型名稱是否正確

你寫的是：

```text
newapi-codex-manager-chatgpt5.6 luna
```

模型 ID 通常不能包含空格，應確認 New API 後台實際的模型名稱，例如：

```text
newapi-codex-manager-chatgpt5.6-luna
```

或：

```text
newapi-codex-manager-chatgpt5.6
```

2. OpenCode 配置需標示圖片輸入

例如：

```json
{
  "provider": {
    "newapi": {
      "npm": "@ai-sdk/openai-compatible",
      "options": {
        "baseURL": "https://你的-newapi地址/v1",
        "apiKey": "[已脱敏]"
      },
      "models": {
        "newapi-codex-manager-chatgpt5.6-luna": {
          "name": "GPT 5.6 Luna",
          "modalities": {
            "input": ["text", "image"],
            "output": ["text"]
          }
        }
      }
    }
  }
}
```

部分 OpenCode 版本可能使用：

```json
{
  "capabilities": {
    "input": ["text", "image"]
  }
}
```

具體欄位要以你目前 OpenCode 版本的配置格式為準。

3. New API 渠道也要支援 vision

後台需要確認：

- 模型渠道不是純文字模型
- 上游模型支援 vision／image input
- 沒有把圖片訊息轉成純文字
- API 兼容格式支援 `image_url`
- 圖片大小和格式符合限制

OpenAI-compatible 請求通常要包含：

```json
{
  "role": "user",
  "content": [
    {
      "type": "text",
      "text": "請分析這張圖片"
    },
    {
      "type": "image_url",
      "image_url": {
        "url": "data:image/png;base64,..."
      }
    }
  ]
}
```

如果 Luna 後端只接受：

```json
{
  "role": "user",
  "content": "請分析這張圖片"
}
```

就代表它目前是文字模式，無法處理圖片。

4. 先用 API 測試模型

可以用 PowerShell 測試：

```powershell
$body = @{
  model = "newapi-codex-manager-chatgpt5.6-luna"
  messages = @(
    @{
      role = "user"
      content = @(
        @{ type = "text"; text = "這張圖片有什麼？" }
        @{
          type = "image_url"
          image_url = @{
            url = "https://example.com/test.png"
          }
        }
      )
    }
  )
} | ConvertTo-Json -Depth 10

Invoke-RestMethod `
  -Uri "https://你的-newapi地址/v1/chat/completions" `
  -Headers @{ Authorization = "Bearer 你的API_KEY" } `
  -ContentType "application/json" `
  -Method Post `
  -Body $body
```

結果判斷：

- API 直接回覆不支援圖片：New API 渠道或上游模型不支援
- API 能處理圖片，但 OpenCode 不行：OpenCode 模型 metadata 配置錯誤
