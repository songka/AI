## 自动归档器实现

新增文件：

- `codex_archive_sync.py`
- `run_codex_archive_sync.ps1`

功能：

- 从 `%USERPROFILE%\.codex\session_index.jsonl` 读取会话索引。
- 从 `%USERPROFILE%\.codex\sessions\**\*.jsonl` 读取会话。
- JSONL 已确认格式：
  - index: `id`, `thread_name`, `updated_at`
  - session record: `type`, `timestamp`, `payload`
  - `session_meta.payload` 包含 `cwd`、`id` 等
  - `response_item.payload` 包含 `role`, `content`
- 导出位置（目标 Git repo 内）：
  ```text
  Codex归档/
    项目名/
      project.json
      源码/
      对话/
  ```
- 每个对话导出 Markdown；单文件超过 `200_000` 字符自动切为 `-001.md`、`-002.md`。
- 仅导出 user/assistant 人类可读内容，不导出工具 payload 或隐藏推理。
- 对导出文本做常见密钥脱敏：
  - Bearer token
  - `sk-*`
  - `ghp_*` / `github_pat_*`
  - `api_key`/`token`/`secret`/`password` 形式。
- 源码复制排除：
  - `.env*`、`auth.json`、`credentials.json`、`secrets.json`
  - `.git`、`.venv`、`node_modules`、`build`、`dist`、缓存等
  - `.pem/.key/.pfx/.p12/.sqlite/.db/.log`
  - 文件超过 10MB
  - 源码文本命中常见 secret pattern 的文件
- 不上传本机绝对路径：
  - `project.json` 仅保留 `name`、哈希 `project_key`、同步时间。
- Git 子进程加了：
  ```python
  -c safe.directory=<repo> -c http.version=HTTP/1.1
  ```
