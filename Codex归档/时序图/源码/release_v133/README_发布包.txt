使用方法：
1. 保持“时序图自动生成工具_v133.exe”和“常用动作时间.json”在同一目录。
2. 双击 EXE 启动。
3. 如需自定义常用动作或公式，可在程序内编辑；配置将保存到同目录 JSON。

注意事项：
- 本工具为 Windows 64 位单文件程序。
- 首次启动可能稍慢，因为单文件程序需要临时解包。
- 当前未进行代码签名，Windows 可能显示未知发布者提示。
- 如中文字体或图片导出异常，请确认系统存在 Microsoft YaHei 等中文字体。
- 详细版本变化请查看“多版本更新优化说明.md”。
