# 第 0 步：建立任务文件夹并归档输入

本技能只处理 Drive 项目定位、输入归档和运行配置，不做品牌识别、不做图片研究、不更新 `assets.json`。

所有时间统一使用北京时间（Asia/Shanghai，UTC+8）。

## Drive 父文件夹

所有项目都必须在 Google Drive 的 `料号` 父文件夹下。

如果找不到 `料号` 文件夹：

- 先询问用户是否创建 `料号` 父文件夹。
- 用户确认后再创建。
- 不要在 Drive 根目录直接创建项目文件夹。

## 项目选择

支持这些用户意图：

- “列出现有项目”：列出 `料号` 文件夹下所有项目，包含项目名、最近更新时间、当前阶段和更新文档摘要。
- “使用/切换到/继续 某项目”：在 `料号` 文件夹下查找该项目，找到后复用，不要新建。
- “展示更新文档/查看项目更新”：读取当前项目的 `项目更新文档.md` 并展示摘要或全文。
- “查看进度/展示进度文件”：读取当前项目的 `项目进度.md` 并展示摘要或全文。

同一个对话只对应一个项目。若本对话已有项目，默认复用；用户明确指定项目时才切换。

如果用户要求“继续之前的”“恢复流程”“接着跑”：

- 先定位当前对话对应项目或用户指定项目。
- 读取 `项目进度.md`、`项目更新文档.md`、`00_项目启动/run_config.json`。
- 检查各步骤目录的最新产物。
- 判断下一步，不要从头重建项目，不要重跑已完成且有效的批次。

如果上一轮显示 `Usage limits exceeded. Not running this agent.`：

- 视为平台额度中断，不要判断为用户取消或文件丢失。
- 优先复用当前项目文件夹，不要要求用户重新上传 TSV 或 `assets.json`。
- 先检查项目内是否已有归档输入、`external_parts_to_process.csv`、`external_parts_priority_queue.csv`、第 1-3 步索引/筛选结果或后续批次文件。
- 如果这些文件存在，直接进入断点续跑。
- 只有项目内缺少原始输入且缺少可恢复队列时，才要求用户补传缺失文件，并明确列出缺什么。

## 项目创建

项目文件夹必须创建在：

```text
料号/{项目名}/
```

项目名优先使用系统可见的对话编号或用户指定名称；没有编号时使用：

```text
external-part-{yyyyMMdd-HHmm}-{任务短名}
```

这里的 `yyyyMMdd-HHmm` 必须使用北京时间。不要为了对话编号阻塞流程。

## 输入归档与配置

1. 将用户上传的所有输入文件复制到当前项目文件夹。
2. 判断 workflow：
   - 有原始 TSV/系统物料表：记录 `workflow_mode=research_1_9`，后续自动执行 1-9。
   - 有已修订的 `人工复核工作簿.xlsx`：记录 `workflow_mode=finalize_10_13`，后续自动执行 10-13。
   - 同时有旧版 `manual_brand_fix.csv` 和 `manual_asset_fix.csv`：记录 `workflow_mode=finalize_10_13`，后续按兼容路径自动执行 10-13；不要要求用户手动把 xlsx 转成 CSV。
3. 如果 `workflow_mode=research_1_9` 且用户同时上传原始 TSV/物料表和 `assets.json` 两个文件，或当前项目已有可用资产索引，必须询问：

```text
请选择 assets.json 处理模式：
1. 更新原资料：保留原记录，并允许后续用新证据补充或替换。
2. 跳过原有：已有资产的料号本轮不再处理。
```

4. 如果 `workflow_mode=research_1_9` 但没有可用资产索引，直接记录 `asset_mode=new_assets`。
5. 询问邮件提醒偏好：

```text
流程全部完成后是否需要邮箱提醒？如需要，请提供收件者邮箱；如不需要，请回复“不需要”。
```

6. 明确记录提醒范围：如果用户设置邮箱提醒，完成、意外打断、流程阻塞、校验失败、缺少输入或需要人工确认时，都要邮件通知或生成邮件草稿。
7. 将配置写入 `00_项目启动/run_config.json`。
8. 将第 0 步结果追加到 `项目更新文档.md`。
9. 创建或更新 `项目进度.md`，写入目录说明和当前完成情况。
10. 在聊天中展示可用提示词简表，并在 `项目进度.md` 中保留完整可用提示词。
11. 用户确认资产处理模式和邮件提醒偏好后，后续必须自动执行第 1-9 步直到导出人工复核文件；中间不要反复询问用户是否继续。


## 输出

- `料号/{项目名}/`
- 已归档输入文件
- `00_项目启动/run_config.json`
- `项目更新文档.md`
- `项目进度.md`

## 停止条件

- 无法找到或创建 `料号` 父文件夹。
- 无法创建或访问项目文件夹。
- 用户要求跑 1-9 但没有原始物料表。
- 存在 `assets.json` 或可用资产索引，但用户还没选择处理模式。
