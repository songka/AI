# 飞书签核对接 — 使用说明书

## 1. 概述

签核工具箱通过飞书实现：通知推送、规则管理卡片、多用户管理、群 @ 触发和个人统计。

## 2. 飞书应用配置

### 2.1 创建应用

[飞书开放平台](https://open.feishu.cn/app) → 企业自建应用 → 添加机器人能力。

### 2.2 权限

| 权限 | 用途 |
|------|------|
| im:message | 发送消息 |
| im:chat:readonly | 读取群信息 |
| contact:user:readonly | 查询用户 |

### 2.3 事件订阅

回调: https://qh.lfaf.eu.org/feishu/event
订阅: im.message.receive_v1 + **card.action.trigger** + **application.bot.menu_v6**

### 2.4 配置 feishu.json

```bash
cp auto-sign/feishu.example.json feishu.json
# 编辑填写 app_id、app_secret、verification_token、webhook_url、receive_id、private_id
/www/server/python_manager/versions/3.9.7/bin/python3 auto-sign/setup.py  # 自动填 bot_open_id
```

`verification_token` 在飞书开放平台的「事件与回调 → 加密策略」中获取。配置后，服务器会拒绝 token 不匹配的伪造回调。

## 3. 功能

### 通知

- 群内公开：只有通知策略允许时才发送；默认不发群
- 签核人显示：优先飞书姓名，其次签核平台登录账号，不再截断显示 `ou_...`
- 成功校验：提交后重新查询；只有目标已从待签列表消失才发送成功群消息
- 拒签消息：逐项显示命中的拒签规则作为“拒签原因”
- 完整显示：每 5 项一张群卡片，完整展示全部成功项目与描述
- 私发管理员：待手动项目有变化 → 私聊通知
- 异常报警：签核失败 → 群内 @对应用户

### 交互卡片

发送「管理中心」可进入规则、组管理和设置。管理卡统一使用 Card JSON 2.0。规则列表点击“编辑”后可修改名称、AND/OR、全部条件、通知方式及拒签理由；用户组和内容组可修改组名与内容，组重命名会同步更新引用规则。卡片操作原地刷新，不会再额外发送重复卡片。签核和拒签仍使用明确文字指令，避免误触。

机器人自定义菜单配置六个事件键：`help`、`query_pending`、`rules`、`groups`、`settings`、`stats`。管理项点击后分别收到规则、组管理、设置或个人统计入口卡片。

### 群 @ 触发

群内 @某人+@机器人 → 以被 @者身份查询并私发通知

### 多用户

首次私聊 → 自动创建独立目录。新用户的签核/拒签/通知规则、用户组和内容组全部为空；现有用户数据保持不变，旧名单只做兼容映射。

## 4. 命令总览

在飞书中发送 `帮助`、`使用说明`、`指令`、`菜单` 或 `怎么用`，可查看带说明和口语示例的完整帮助卡片。

| 类别 | 标准指令 | 常见口语 |
|------|----------|----------|
| 查询 | `查询` | 查一下、我的待办、有什么要签、有没有料号、现在要签什么 |
| 预览 | `模拟自动签核` | 只显示真实执行后的动作与群通知判断；本次不提交、不发群 |
| 单次自动 | `执行一次自动签核` | 自动签核一次、立即自动签核；只处理当前规则命中项 |
| 指定签核 | `签核 1 3 5-8` | 同意第2个、通过 1、帮我签 3、签一下 2-5 |
| 指定拒签 | `拒签 2 4 原因:资料不完整` | 原因可选；未填写时使用拒签规则理由 |
| 批量操作 | `全签`、`全拒` | 始终需要再次发送 `确认` |
| 账户 | `登录`、`状态`、`登出` | 我要登录、当前账号、我是谁、退出登录、重新登录 |
| 规则 | `规则`、`规则文本`、`加规则`、`删规则`、`暂停规则`、`AI加规则` | 看规则、我的规则、新增规则、智能加规则、帮我加规则 |
| 组 | `组管理`、`用户组`、`内容组` | 组、分组、人员组；全部通过卡片编辑 |
| 设置 | `设置` | 卡片编辑启停、时间、间隔、等待、群通知默认值 |
| 统计 | `统计` | 飞书 OAuth 个人网页，可统计、编辑规则和设置、导出 Excel |

查询结果会按每页 5 项分卡片发送，展示全部待签项目及完整的申请单号、申请人、描述、单位、类别和规则判断，不再截断为前 20 项或 45 个字符。

AI 可以自然聊天和判断意图，但永远不会直接执行签核、拒签、全签或全拒；只会提示用户输入明确指令。

## 5. CLI 命令

```bash

python3 auto-sign/qh.py feishu send    # 手动执行定时任务
python3 auto-sign/qh.py feishu serve   # 本地回调服务
```
