概念拆解：IO 表检查实操中每一部分是什么

1. 大语言模型（LLM）
位置：
- 根据提示词理解 IO 表、工具结果和检查规则。
- 把工具输出转换成工程语言。
它做什么：
- 总结、分类、生成建议。
它不做什么：
- 不直接确认安全回路是否完整。
- 不直接修改 PLC 程序。

2. 技能（Skill）
位置：
- skill/SKILL.md
它做什么：
- 规定检查顺序、输出格式、人工确认边界。
它不做什么：
- 不保存所有项目资料。
- 不替代电控工程师签字。

3. 智能体（Agent）
位置：
- 课堂中可以让学员手工扮演，也可以由平台自动执行。
它做什么：
- 按目标推进步骤：读取 IO 表 -> 调工具 -> 查规则 -> 生成评审表 -> 标记人工确认点。
它不做什么：
- 不越权读取无关项目。
- 不自动下发程序或修改设备参数。

4. 模型上下文协议（MCP）/工具
位置：
- outputs/skill-examples/io-table-review/scripts/check_io_table.py
它做什么：
- 对 CSV 做确定性检查：空字段、重复地址、重复 tag。
它不做什么：
- 不判断安全逻辑是否完整。
- 不理解项目背景。

5. 知识库
位置：
- skill/references/io-rules.md
它做什么：
- 提供正式检查规则、命名规则、人工确认点。
它不做什么：
- 不自动执行检查。

6. 记忆（Memory）
位置：
- 本案例不强制使用记忆。
可记内容：
- 部门偏好输出“风险、证据、建议、责任岗位”四列。
不应记内容：
- 客户项目名称、设备图纸、PLC 程序、报价、密码。

7. 工作流（Workflow）
位置：
- README.txt 中的课堂顺序。
它做什么：
- 把输入、技能、工具、知识库、人工复核串成稳定步骤。
它不做什么：
- 不跳过人工确认。
