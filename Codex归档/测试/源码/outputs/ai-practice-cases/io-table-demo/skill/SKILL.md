# IO 表预审技能（Skill）

## 适用场景

当用户提供非标自动化设备 IO 表，需要做课前演示或项目预审时使用。

## 输入材料

1. IO 表 CSV 文件。
2. 工具检查结果 CSV。
3. IO 检查规则文件。

## 执行步骤

1. 先用工具检查 CSV 的确定性问题：
   - 必填字段为空。
   - 地址重复。
   - tag 重复。
   - 必需列缺失。
2. 再按规则检查工程风险：
   - 安全门、急停、复位、报警等信号是否清晰。
   - 同一设备的伸出、缩回、原点、到位信号是否成组出现。
   - tag 命名是否能看出工位、设备、动作或状态。
3. 输出时必须区分：
   - 工具已经确定的问题。
   - 需要工程师确认的问题。
4. 不得把猜测写成事实。
5. 最后给出是否建议进入下一步。

## 输出格式

问题类型,证据,影响,建议处理,责任岗位,是否需要人工确认

## 边界

本技能（Skill）只做预审，不做最终电气设计结论。
涉及安全、互锁、PLC 程序、设备动作的结论必须由电控工程师确认。
