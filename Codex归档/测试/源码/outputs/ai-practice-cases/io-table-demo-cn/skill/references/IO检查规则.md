# IO 表检查规则

## 确定性检查

- 工位、设备、信号类型、地址、变量名、说明不能为空。
- 地址不应重复，除非项目规则明确允许。
- 变量名不应重复。
- 信号类型应能区分 DI、DO、AI、AO。

## 工程风险检查

- 安全门、急停、复位、报警相关信号必须描述清楚。
- 气缸类设备通常需要伸出、缩回、到位或原点相关信号。
- 视觉、扫码、称重等设备应有完成、合格、不合格、异常或超时处理逻辑。
- 变量名应包含工位、设备、动作或状态，避免只写简单编号。

## 人工确认点

- 安全回路是否完整。
- 互锁逻辑是否满足设备动作要求。
- PLC 程序是否按 IO 表实现。
- 现场调试是否验证通过。
