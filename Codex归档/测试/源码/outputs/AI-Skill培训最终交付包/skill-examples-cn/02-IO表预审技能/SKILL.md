# IO表预审技能

## 什么时候使用
当用户提供 IO 表、点位清单、传感器清单、执行元件清单，要求检查命名、点位、地址、备注和风险时，使用本技能。

## 工作目标
帮助电控工程师在设计早期发现 IO 表中的漏项、命名不统一、地址重复、备注不足和安全相关风险。

## 操作步骤
1. 先阅读 `references/IO检查规则.md`。
2. 打开用户提供的 IO 表或 `assets/IO表样例.csv`。
3. 如需自动检查，运行 `scripts/检查IO表.py`。
4. 对工具结果进行人工解释，不能只贴工具输出。
5. 输出“问题清单 + 修改建议 + 需要确认的问题”。

## 输出格式
请输出三段：
1. 总体结论：能否进入下一步设计。
2. 问题清单：按高、中、低风险排序。
3. 修改建议：给出可直接改写的中文命名或备注。

## 注意
工具只能检查格式化问题，不能完全替代工程判断。例如安全回路、互锁逻辑、动作时序仍需要工程师确认。
