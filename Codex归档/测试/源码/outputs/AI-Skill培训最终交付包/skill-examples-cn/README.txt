中文 Skill 示例目录

用途：
本目录给“Skill（技能）”课程使用，所有示例尽量采用中文文件名、中文说明、中文业务内容，方便电控工程师、机构工程师、项目/文职人员、生物管/质量人员直接照着拆解。

建议课堂用法：
1. 先打开每个示例的 SKILL.md，看“这个技能什么时候触发、先读什么、输出什么”。
2. 再打开 references 文件夹，看业务规则怎样被拆成可复用知识。
3. 再打开 assets 文件夹，看模板、样例表、清单怎样给智能体当参考材料。
4. 如果有 scripts 文件夹，再说明：脚本是“可执行工具”，不是每个 Skill 都必须有。

四个示例：
01-方案评审技能：适合机构、电控一起看，用来预审方案是否缺信息。
02-IO表预审技能：适合电控工程师重点看，包含可运行脚本。
03-项目资料归档技能：适合文职、项目助理、生物管等资料岗位。
04-验证文档预检技能：适合生物管、质量、验证人员，用来检查记录完整性。

一句话理解：
Skill 不是一句提示词，而是一套“说明书 + 规则库 + 模板 + 可选工具”的文件夹。
