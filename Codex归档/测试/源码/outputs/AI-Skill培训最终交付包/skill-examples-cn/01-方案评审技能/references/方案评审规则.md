# 方案评审规则

## 必查信息
1. 产品信息：产品名称、尺寸、重量、材质、来料状态、方向要求。
2. 工艺信息：动作流程、关键工位、节拍、精度、良率、异常处理。
3. 设备边界：人工上下料还是自动上下料，是否对接前后段设备。
4. 电控信息：传感器、扫码、相机、PLC、上位机、数据追溯、报警。
5. 机构信息：定位、夹紧、搬运、导向、防呆、易损件、换型。
6. 安全信息：急停、门禁、光栅、防护罩、气压检测、权限控制。
7. 验收信息：验收指标、测试样本数量、验收方法、客户签核方式。

## 风险等级
高：影响报价、周期、安全、验收或核心工艺。
中：影响设计细节、采购选型、调试效率。
低：影响文档完整性或后续沟通效率。

## 常见风险
1. 节拍只写目标，没有说明动作分解和瓶颈工位。
2. 只写“扫码追溯”，没有说明扫码内容、绑定规则、数据保存位置。
3. 只写“自动检测”，没有说明检测项目、判定标准、误判处理。
4. 只写“兼容多规格”，没有说明规格范围、换型方式、换型时间。
5. 只写“客户提供样品”，没有说明样品数量、状态、是否可破坏测试。
