# Project Doc Archive

Use this skill to standardize project document organization and reduce missing follow-ups.

## Workflow

1. Read `references/archive-rules.md` for the folder stages and required document types.
2. Identify the project code, customer, equipment name, current phase, and document version when available.
3. Classify materials into sales handoff, scheme, design, procurement, assembly, commissioning, acceptance, and after-sales.
4. Produce the folder structure using `assets/archive-structure-template.txt`.
5. Create a missing-document checklist and an action tracker.
6. Highlight items that need customer confirmation or internal owner follow-up.

## Output Rules

- Never recommend deleting original files.
- Preserve version and date information when visible.
- If a document appears in the wrong phase, suggest where to copy or reference it rather than silently moving it.
- Output tables that can be pasted into Excel.
