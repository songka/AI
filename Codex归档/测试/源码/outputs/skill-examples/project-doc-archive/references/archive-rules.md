# Project Archive Rules

1. 00-sales-handoff
2. 01-scheme
3. 02-design
4. 03-procurement
5. 04-assembly

## Required Documents

- Customer URS or requirement notes
- Quotation and scope boundary
- Project schedule
- Meeting minutes and customer confirmations
- Design review records
- BOM or purchasing list
- FAT/SAT or acceptance records
- Open issue tracker

## Action Tracker Fields

- action
- owner
- source
- due_date
- risk_if_late
- current_status
