# Scheme Review Rules

## Required Context

- Customer and project name
- Product type, variant count, and incoming material state
- Process flow and station sequence
- Target cycle time and capacity assumptions
- Acceptance criteria and test method
- Site constraints: space, power, air, utilities, cleanroom, safety
- Known standards or customer templates

## Review Categories

1. Process risk: unclear process sequence, missing product state, unknown tolerance, manual intervention.
2. Mechanical risk: positioning, clamping, rigidity, maintenance space, changeover, wear parts.
3. Electrical risk: sensor strategy, safety circuit, IO count, cabinet location, network, traceability.
4. Software risk: recipe management, data recording, barcode/MES interface, alarm handling.
5. Delivery risk: long-lead parts, customer sample timing, acceptance resources, site readiness.

## Priority Guide

- High: safety, acceptance, cycle time, product damage, missing key input.
- Medium: maintainability, changeover, unclear ownership, noncritical data interface.
- Low: wording, formatting, minor convenience improvement.
