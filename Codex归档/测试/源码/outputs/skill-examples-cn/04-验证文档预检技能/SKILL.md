# 验证文档预检技能

## 什么时候使用
当用户提供验证方案、验证记录、测试记录、确认报告，要求检查完整性和一致性时，使用本技能。

## 工作目标
提前发现验证文档中的缺项、签核缺失、数据不一致、偏差未关闭等问题。

## 操作步骤
1. 先阅读 `references/验证规则.md`。
2. 对照用户提供的验证资料逐项检查。
3. 使用 `assets/问题清单模板.csv` 输出问题。
4. 把“能由智能体建议修改”和“必须由用户确认”的内容分开。

## 输出格式
输出：
1. 文档完整性结论。
2. 问题清单。
3. 建议修改文字。
4. 必须人工确认的问题。

## 注意
涉及真实验证结论、偏差关闭、签核责任时，智能体只能辅助检查，不能替代责任人签核。
