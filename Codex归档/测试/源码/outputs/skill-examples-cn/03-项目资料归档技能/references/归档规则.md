# 归档规则

## 推荐一级目录
01-客户输入
02-方案与评审
03-机械设计
04-电控设计
05-软件程序
06-采购与BOM
07-装配调试
08-验证与验收
09-变更记录
10-交付资料

## 文件命名建议
项目编号_资料类型_版本_日期_负责人

示例：
P20260706_IO表_V1_20260706_张三.xlsx
P20260706_方案评审纪要_V2_20260710_李四.docx

## 常见问题
1. 文件名只有“新建文档”“最终版”“最终最终版”。
2. 图纸、BOM、程序版本不一致。
3. 验收资料缺少签字版。
4. 客户输入资料没有原始版本。
5. 变更只有口头记录，没有变更单。
