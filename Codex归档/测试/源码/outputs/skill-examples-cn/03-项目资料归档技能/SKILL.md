# 项目资料归档技能

## 什么时候使用
当用户要整理项目资料、交付资料、会议纪要、图纸、BOM、程序、验证记录时，使用本技能。

## 工作目标
把零散文件整理成可追溯、可交接、可审计的项目资料目录。

## 操作步骤
1. 先阅读 `references/归档规则.md`。
2. 根据用户提供的文件名、文件夹截图或资料清单判断分类。
3. 使用 `assets/资料目录模板.txt` 输出建议目录。
4. 标出缺失资料、命名不规范资料、需要负责人确认的资料。

## 输出格式
输出四部分：
1. 推荐目录结构。
2. 已有资料应该放哪里。
3. 缺失资料清单。
4. 需要用户确认的问题。

## 注意
不要随意删除或重命名用户文件。只给建议，真正改名和归档前需要用户确认。
