# 機構2D自動報價系統目前執行計劃

## 目標

建立一套可以實際使用的自動報價系統。

不要一開始做完整AI。

按照以下順序。

------------------------------------------------------------------------

# 第一階段：建立報價核心

目標：

完成不用AI也可以運行的版本。

需要完成：

-   DXF解析。
-   文件夾掃描。
-   特徵提取。
-   規則引擎。
-   Excel輸出。

輸入：

DXF文件。

輸出：

報價Excel。

------------------------------------------------------------------------

# 第二階段：整理你的報價規則

需要收集：

## 材料

例如：

-   AL6061。
-   SUS304。
-   SKD11。

資料：

-   單價。
-   密度。
-   損耗。

------------------------------------------------------------------------

## 加工

建立：

-   CNC加工費。
-   車床加工費。
-   磨床。
-   線割。
-   鈑金。

------------------------------------------------------------------------

## 表面處理

例如：

-   陽極。
-   發黑。
-   鍍鎳。
-   熱處理。

------------------------------------------------------------------------

# 第三階段：建立歷史報價庫

收集：

-   過去報價Excel。
-   成交價格。
-   供應商報價。

AI整理：

-   零件分類。
-   特徵。
-   價格。

形成：

歷史報價資料庫。

------------------------------------------------------------------------

# 第四階段：加入AI

AI負責：

-   技術文字理解。
-   工藝推薦。
-   相似案例查找。
-   未知項說明。

AI不能：

-   自由定價。
-   修改規則。

------------------------------------------------------------------------

# 第五階段：開發GUI

最後開發：

MechanicalQuotation.exe

功能：

-   選文件夾。
-   開始分析。
-   查看未知項。
-   確認AI建議。
-   導出Excel。

------------------------------------------------------------------------

# 現在立即要做的事情

## Step 1

準備資料：

1.  10\~50份DXF圖紙。
2.  10份人工報價Excel。
3.  材料價格表。
4.  加工價格表。
5.  一份你現在使用的報價模板。

------------------------------------------------------------------------

## Step 2

讓Claude Code開始：

要求：

1.  分析現有項目。
2.  建立CLI框架。
3.  建立DXF解析模塊。
4.  建立測試框架。

------------------------------------------------------------------------

## Step 3

不要先做AI。

先驗證：

同一張圖：

人工報價 vs 系統報價

差異原因。

------------------------------------------------------------------------

# 第一版成功標準

可以：

-   自動讀DXF。
-   自動識別材料。
-   自動計算部分加工。
-   輸出Excel。
-   標記C/E/U。

即算成功。

AI和學習功能後續增加。
