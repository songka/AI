# 機構2D自動報價系統架構與角色分工

## 一、核心定位

本系統不是單純AI報價，而是：

> 規則驅動的自動報價系統 + AI工程輔助判斷

核心原則：

-   CAD解析、尺寸計算、價格計算由程序完成。
-   AI負責語義理解、行業資料整理、候選方案。
-   正式價格必須可追溯。

------------------------------------------------------------------------

# 二、系統角色

## 1. 人

負責：

-   選擇圖紙或文件夾。
-   確認未知項。
-   修改AI建議。
-   維護公司規則。

------------------------------------------------------------------------

## 2. 報價軟件

負責：

-   文件管理。
-   任務管理。
-   調用解析程序。
-   展示結果。
-   生成Excel。

------------------------------------------------------------------------

## 3. CAD解析程序

負責：

-   DXF/DWG讀取。
-   尺寸提取。
-   孔數量。
-   輪廓。
-   材料文字。
-   技術要求。

禁止使用圖片模型替代。

------------------------------------------------------------------------

## 4. 報價規則引擎

負責：

-   材料價格。
-   加工工時。
-   表面處理。
-   外購件。
-   成本公式。

------------------------------------------------------------------------

## 5. AI模塊

負責：

-   材料名稱整理。
-   技術文字理解。
-   加工工藝候選。
-   行業資料整理。
-   未知項說明。

不能直接決定正式價格。

------------------------------------------------------------------------

# 三、價格來源分級

  代碼   來源       說明
  ------ ---------- --------------
  C      公司規則   正式確認價格
  H      歷史報價   公司過去案例
  E      行業標準   行業參考
  AI     AI建議     模型分析
  M      人工確認   人工選擇
  U      未知       無法判斷

------------------------------------------------------------------------

# 四、行業數據庫來源

沒有單一完整行業數據庫。

應由以下組成：

## 1. 公司歷史報價

最高優先級：

-   歷史報價單。
-   成交價格。
-   成本核算。
-   供應商報價。

------------------------------------------------------------------------

## 2. 供應商價格

來源：

-   CNC廠。
-   線割廠。
-   表面處理廠。
-   熱處理廠。

------------------------------------------------------------------------

## 3. 材料價格

來源：

-   採購價格。
-   材料供應商。
-   市場資料。

------------------------------------------------------------------------

## 4. 行業參考

來源：

-   加工廠經驗。
-   ERP成本模型。
-   工程師經驗。

------------------------------------------------------------------------

# 五、流程角色

``` mermaid
flowchart TD

E -->|命中| F[C確認]
E -->|未命中| G{歷史報價}
G -->|找到| H[歷史參考]
G -->|沒有| I{行業庫}

K --> L[人工確認]

J --> N
M --> N
```

------------------------------------------------------------------------

# 六、最終原則

AI不是報價員。

正確模式：

規則 \> 歷史 \> 行業 \> AI \> 人工確認
