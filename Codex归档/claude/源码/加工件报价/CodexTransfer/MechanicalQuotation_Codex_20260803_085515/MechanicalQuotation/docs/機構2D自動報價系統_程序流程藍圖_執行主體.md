# 機構2D自動報價系統 程序流程藍圖

## 執行主體說明

標記：

-   \[人\] 人員操作
-   \[軟件\] 本地程序
-   \[規則引擎\] 固定算法
-   \[AI\] AI模型
-   \[資料庫\] 數據存儲

------------------------------------------------------------------------

``` mermaid
flowchart TD

A[人: 選擇圖紙/文件夾]
-->B[軟件: 掃描文件]

B
-->C[軟件: 篩選DXF/DWG]

C
-->D[軟件: CAD解析]

D
-->E[軟件: 提取尺寸/孔/輪廓/文字]


E
-->F{規則引擎: 匹配公司報價規則}


F
-- 命中 -->
G[規則引擎: C規則確認價格]


F
-- 未命中 -->
H{資料庫: 查找歷史報價}


H
-- 找到 -->
I[資料庫: H歷史參考]


H
-- 沒找到 -->
J{資料庫: 查找行業規則}


J
-- 找到 -->
K[規則引擎: E行業推測]


J
-- 沒找到 -->
L[AI: 分析文字與工藝]


L
-->M[AI: 提供候選方案]


M
-->N[人: 確認或修改]


N
-->O[規則引擎: 更新計算]


G
-->P[軟件: 生成Excel]

I
-->P

K
-->P

O
-->P

P
-->Q[軟件: 保存JSON與日志]


Q
-->R[資料庫: 保存歷史案例]
```

# 人員日常操作流程

``` mermaid
flowchart TD

A[人: 打開軟件]
-->B[人: 選擇項目文件夾]

B
-->C[軟件: 自動分析]

C
-->D[軟件: 顯示報價結果]

D
-->E{存在未知項?}

E
--否-->

E
--是-->
G[人: 查看AI建議]

G
-->H[人: 確認]

H
-->F

F
-->I[資料庫保存案例]
```
