# AI與行業知識庫設計

## 一、AI定位

AI是工程助手，不是價格決策者。

------------------------------------------------------------------------

# 二、AI可以做

## 文字理解

例如：

6061鋁

AL6061

6061-T6

統一：

AL6061

------------------------------------------------------------------------

## 工藝分析

輸入：

平面度0.01

Ra0.8

輸出：

可能：

-   精銑。
-   磨削。

需要人工確認。

------------------------------------------------------------------------

## 行業資料整理

AI可以：

-   收集資料。
-   整理格式。
-   建立候選規則。

不能：

直接把網路價格加入正式報價。

------------------------------------------------------------------------

# 四、資料更新流程

``` mermaid
flowchart LR
A[外部資料] --> B[AI整理]
B --> C[人工確認]
C --> D[知識庫]
D --> E[報價系統]
```

------------------------------------------------------------------------

# 五、價格優先級

1.  公司正式規則
2.  公司歷史報價
3.  供應商價格
4.  行業參考
5.  AI建議

------------------------------------------------------------------------

# 六、未知項處理

如果沒有可靠資料：

輸出：

狀態：

U 未知

不要猜價格。

------------------------------------------------------------------------

# 七、AI模式

## 關閉AI

系統仍可：

-   解析。
-   計算。
-   報價。

## 開啟AI

增加：

-   語義理解。
-   工藝推薦。
-   相似案例。
