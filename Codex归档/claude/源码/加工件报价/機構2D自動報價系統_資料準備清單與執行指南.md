# 機構2D自動報價系統 - 資料準備清單與執行指南

## 目的

在開始開發前，需要準備以下資料，使 Claude Code
能建立真正符合公司報價方式的系統。

目標不是讓 AI 猜價格，而是建立：

CAD解析 + 公司規則 + 歷史經驗 + AI輔助 的報價系統。

------------------------------------------------------------------------

# 一、目前需要準備的資料

## 1. CAD圖檔樣本（最高優先）

準備：

-   DXF
-   DWG（如果有）

建議數量：

第一批： 10\~20個

完整測試： 50\~100個

分類：

## CNC加工件

例如：

-   支架
-   底板
-   安裝座
-   精密零件

## 車削件

例如：

-   軸
-   套筒
-   螺紋件

## 鈑金件

例如：

-   折彎件
-   焊接件

## 複雜件

例如：

-   多工序零件
-   高精度零件

每個圖檔最好包含：

-   材料
-   數量
-   表面處理
-   公差
-   技術要求

------------------------------------------------------------------------

# 二、人工報價資料

準備過去：

-   報價Excel
-   報價單

-   外發加工價格

每筆最好包含：

  欄位       內容

  供應商

建立歷史報價庫。

# 三、建立正式報價規則

需要整理：

## 材料規則

例如：

AL6061：

-   密度
-   kg價格
-   損耗比例

SUS304：

-   kg價格

------------------------------------------------------------------------

## 加工規則

例如：

CNC：

  條件       價格
  ---------- ---------
  普通三軸   150元/h
  精密加工   250元/h

車床：

  條件       價格
  ---------- ---------
  普通車削   120元/h

------------------------------------------------------------------------

## 表面處理

例如：

-   陽極氧化
-   發黑
-   鍍鎳
-   熱處理

需要：

-   單價
-   計價方式
-   最低消費
