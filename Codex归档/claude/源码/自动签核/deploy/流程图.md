## 3. 定时任务流程（每分钟）

```
计划任务触发 cli_feishu.py send
  │
  ▼
遍历 users/ 下所有已登录用户
  │
  ├─ 自动签核已暂停？ ─── 是 ──→ 跳过
  │       否
  ├─ 不在个人时间窗口？ ─ 是 ──→ 跳过
  │       否
  ├─ 未到间隔时间？ ──── 是 ──→ 跳过
  │       否
  ▼
┌──────────────────────┐
│ 用该用户凭证登录 GSC   │
│ 抓取待签列表          │
│ 加载个人规则（排除暂停）│
└──────┬───────────────┘
       │
       ▼
┌──────────────────────┐
│ 检查等待条件           │
│ check_wait_for()     │
└──────┬───────────────┘
       │
  ┌────┴────┐
  │ 有人在等？│
  └────┬────┘
   是  │  否
   ▼   │   ▼
┌──────────────┐  ┌──────────────┐
│ 等的人已签完？ │  │ 规则匹配      │
│ (有签核记录)  │  │ 自动签核/拒签 │
└──┬───────────┘  └──────┬───────┘
   │是          否        │
   ▼           ▼         ▼
┌────────┐  ┌────┐  ┌──────────┐
│30-60s  │  │跳过 │  │ 执行签核  │
│随机延时│  └────┘  │ 记录事件  │
│重取数据│          │ 群通知    │
│自动签核│          │ @用户     │
└───┬────┘          └──────────┘
    │
    ▼
┌──────────────┐
│ 执行签核      │
│ 群通知:      │
│ 张三-自动签核 │
│ 异常:@张三   │
└──────────────┘
```

## 4. 飞书消息处理

```
飞书回调 POST /feishu/event
  │
  ├─ url_verification → 返回 challenge
  ├─ card.action.trigger → 卡片按钮处理
  └─ im.message.receive_v1 → 消息处理
       │
       ├─ 私聊 (p2p)
       │    ├─ 登录/登出/状态
       │    ├─ 规则/加规则/删规则/AI加规则
       │    ├─ 暂停规则/暂停自动签核
       │    ├─ 设时间/等签核/取消等待
       │    ├─ 查询/卡片
       │    ├─ 签核 X/拒签 X/全签/全拒
       │    └─ 帮助
       │
       └─ 群聊 (group)
            ├─ 是否 @机器人？ → 否 → 忽略
            └─ 是 → 防抖5分钟
                 ├─ @了其他用户 → 用该用户身份查询通知
                 └─ 仅 @机器人 → 触发全局 fetch+send
```

## 5. 等待签核流程

```
A 设置: 等签核 B approve
  │
  ├─ 检查: B 是否设置等 A？ → 是 → 拒绝（循环）
  ├─ 检查: B 是否间接等 A？ → 是 → 拒绝（闭环）
  └─ 通过 → 保存设置

每次 A 的定时任务:
  │
  ▼
check_wait_for(A)
  ├─ B 在待签列表中？ → 是 → 不触发
  ├─ B 有签核记录？(时间 > 上次检查)
  │    └─ 否 → 不触发
  └─ 是 → 30-60s 随机延时
            → 重新获取最新数据
            → 执行 A 的签核
            → mark_wait_checked(A)
            → record_sign_event(A, approve)
```

```
  ▼

```

## 7. 数据流

```
feishu.json ──→ 飞书 API 配置
config.json ──→ GSC 平台 URL/SSL
sign_events.json ←── 签核事件记录（等待检测用）

users/ou_xxx/
  auth.json ←── 登录时写入
  rules.json ←── 加规则/AI加规则/删规则
  settings.json ←── 设时间/暂停/等签核
  whitelist.txt ←── 用户编辑
```
