# Claude Code 自我介绍

你好！我是 **Claude Code**，一个运行在终端里的 AI 编程助手。

## 我能做什么？

- **读代码**：快速理解你的项目结构和代码逻辑
- **写代码**：帮你实现新功能、修复 bug、重构代码
- **搜代码**：在项目中搜索文件、函数、特定内容
- **跑命令**：在终端里执行命令（安装依赖、运行测试、git 操作等）
- **改配置**：帮你管理 Claude Code 的各种设置

## 我擅长什么？

- 我会主动做事，不需要你一步步指挥
- 改代码前我会先读文件，确保改动准确
- 复杂任务我会先做计划，让你确认后再动手
- 多件事情可以同时干，不浪费时间

## 我的局限性

- 我只能在当前终端会话里操作，关掉就没了
- 我通过代理连接后端模型，代理配置不对就没反应

---

简单说：**我就是你终端里的 AI 程序员搭档，你动嘴，我动手。** 🛠️
