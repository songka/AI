Index 60FD 
Description VarCom - IN 
Indicates the state of the digital inputs. 
The digital inputs object has 32 bits.  
The first 16 bits (bits 0-15) indicate the status of various types of 
switches. Those switches are functions assigned to some of the 
digital inputs. 
bit 0: Negative limit switch 
1=digital input assigned to the negative limit switch is on. 
0=digital input assigned to the negative limit switch is off. 
bit 1: Positive limit switch 
1=digital input assigned to the positive limit switch is on. 
0=digital input assigned to the positive limit switch is off. 
bit 2: Home switch 
1=digital input assigned to the home switch is on. 
0=digital input assigned to the home switch is off. 
bit 3: STO status 
1= 24V is not supplied to drive STO module; drive is in Safe 
Torque Off state. 
0= 24V is supplied to drive STO module 
 
The last 16 bits indicate the status of each digital input, 
regardless of the input’s functionality. 
bit 16: digital input 1 
bit 17: digital input 2 
... 
bit 25: digital input 10 
bit 26: digital input 11 
If input is on, corresponding bit is set.

60FEh: Digital Outputs 
Object Description 
Index 60FE 
Description VarCom - OUT 
Indicates the state of the digital outputs. The object has two 
sub-indices. 
Sub-index 1 has 32 bits. The bits in the first word (bits 0-15) 
indicate the status of the brake. 
bit 0 = brake (CDHD2 drives do not support this bit) 
0 = Digital output is off, brake is not set 
1 = Digital output is on, brake is set 
The bits in the second word (bits 16-31) indicate the state of 
each digital output, regardless of the output’s functionality. For 
example, to read the status of digital output 1 (regardless of its 
functionality; it can be idle), read bit 16. 
bit 16: Digital output 1 
bit 17: Digital output 2 
bit 18: Digital output 3 
… and so on  
Possible bit values: 
0 = off 
1 = on 
 
Sub-index 2 - Mask for the physical outputs.  
Possible bit values: 
0 = Disable output (output state will not be changed) 
1 = Enable output (output state can be changed)

12 CANopen and EtherCAT Troubleshooting 
1.1 Warning Codes 
CDHD2 warnings are reported in object 2011h. 
CDHD2 warnings are 64 bits, divided into two 32-bit segments. 
Refer to the section Warning Messages in the CDHD2 User Manual. 
1.2 Error Codes 
If the master device issues an invalid SDO request to the drive, the drive returns a service 
request error (abort) code to the master. 
An SDO operation may return one of the SDO abort codes specified in the CANopen 
standard, listed in Table 12-1. 
If an SDO fails due to a manufacturer-specific error, the SDO abort code will be 08000000h 
(general error) and the detailed error code will be available in object 216Ch. 
Refer to the section Error Messages in the CDHD2 User Manual.
