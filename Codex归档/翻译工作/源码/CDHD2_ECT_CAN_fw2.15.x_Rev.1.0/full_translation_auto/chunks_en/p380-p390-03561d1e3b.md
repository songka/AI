Object Description 
Index 2179 
Description VarCom - HALLSONLYCOMM 
Defines Halls-only commutation.

compatible). 
1 = Commutation is based on an extrapolated position while 
velocity exceeds the defined threshold of Hall signals per 
second  and changes to six-step when velocity falls below 
75% of the Hall signals per second threshold.
