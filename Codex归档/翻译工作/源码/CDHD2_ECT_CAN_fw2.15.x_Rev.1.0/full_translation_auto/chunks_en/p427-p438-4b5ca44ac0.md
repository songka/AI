Object Description 
Index 6040 
Description Used to control the CiA-402 FSA, CiA-402 modes and 
manufacturer-specific entities.

meaning: 
bit 0: Switch on 
bit 1: Enable voltage 
bit 2: Quick stop 
bit 3: Enable operation 
bits 4-6: Mode specific 
bit 7: Fault reset 
bit 8: Halt

bit 10: Reserved
