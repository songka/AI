60C4h: Interpolation Data Configuration 
Object Description 
Index 60C4 
Description Configures and handles the buffer for the data records, and 
configures the data records. 
Sub-index 1- The number of interpolation data records. 
Sub-index 2 - The number of interpolation data records. 
Sub-index 3 - Specifies the buffer organization: 
    0 = FIFO 
    1 = ring 
Sub-index 4 - The next free buffer entry point. 
Sub-index 5 - The size of the data record. 
Sub-index 6 - Clears the buffer. 
Writing 0 to sub-index 6 clears the buffer inputs, disables 
access, and clears all IP data records.  
Writing 1 to sub-index 6 enables access to the input buffers.

60F2h: Positioning Option Code 
Object Description 
Index 60F2 
Description The configured positioning behavior, as described by the profile 
positioning mode or the interpolated positioning mode. 
This object is organized bit-wise. The bits have the following 
meaning: 
bit 0,1: relative option 
bit 2,3: change immediately option 
bit 4,5: request-response option 
bit 6,7: reserved 
bit 8-11: ip option 
bit 12-14: reserved 
bit 15: manufacturer-specific
