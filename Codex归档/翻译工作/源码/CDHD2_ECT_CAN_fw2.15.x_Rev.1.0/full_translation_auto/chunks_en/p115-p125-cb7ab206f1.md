Description Contains the communication parameters of the current PDO the

1600h: Receive PDO Mapping Parameter 1  
Object Description 
Index 1600 
Description Contains the mapping for the PDOs the device is able to receive. 
Sub-index 0 - Defines the number of valid entries in the 
mapping record. This number of entries is also the number of 
the application variables that are received with the 
corresponding PDO. 
Sub-index 1 to [number of entries] - Contain information about 
the mapped application variables. These entries describe the 
PDO contents by their index (16 bit), sub-index (8 bit) and 
length (8 bit).  
Object Code Record 
Data Type Manufacturer-specific, varies by sub-index.
