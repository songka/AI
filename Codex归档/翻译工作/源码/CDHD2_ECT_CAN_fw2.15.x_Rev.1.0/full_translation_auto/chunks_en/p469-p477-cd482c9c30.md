60B2h: Torque Offset 
Object Description 
Index 60B2 
Description VarCom - EXTADDITIVEICMD 
Torque offset value. Takes a commanded current value from the 
host controller and adds it to the current command entering the 
current loop. 
In Cyclic Synchronous Position mode and Cyclic Synchronous 
Velocity mode, this object contains the input value for torque 
feed forward. 
In Cyclic Synchronous Torque mode, it contains the commanded 
additive torque of the drive, which is added to the target torque 
value. 
The value itself is absolute and thus independent of how often it 
is transmitted over the communication system; that is, twice 
transmitted does not mean double value.

Data Type INTEGER16

probe 1

probe 2

touch probe 2 
           bit value = 1: enable sampling at negative edge of touch 
probe 2

60C0h: Interpolation Submode 
Object Description 
Index 60C0 
Description Defines the interpolation mode. 
0 = Linear interpolation 
-x = Manufacturer-specific 
If linear interpolation is the only algorithm avalaible, it is not 
necessary to implement this object. 
If the linear interpolation mode is selected, the interpolation 
data given in the interpolation data record is used. 
If a manufacturer-specific interpolation mode is selected, the 
corresponding interpolation data record must be implemented 
in the manufacturer-specific profile area of the object dictionary.

Entry Description

60C1h: Interpolation Data Record 
Object Description 
Index 60C1 
Description This object indicates the number of data words, which are 
needed for execution of the interpolation algorithm. The 
number of data words in the record is defined by interpolation 
data configuration 
The interpretation of the data words in the interpolation data 
record may vary due to the various possible modes and 
submodes that can be selected. 
For the linear interpolation mode, each interpolation data 
record simply is regarded as a new position set-point.
