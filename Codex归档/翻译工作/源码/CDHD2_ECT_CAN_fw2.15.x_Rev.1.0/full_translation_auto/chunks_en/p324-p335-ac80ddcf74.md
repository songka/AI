2100h: Analog Input 2 Mode 
Object Description 
Index 2100 
Description VarCom - ANIN2MODE 
Defines the function of analog input 2. 
Possible values: 
-1= Hardware defined dual gain. ANIN2 is inactive, ANIN1 has 
a 16 bit resolution, ANIN2MODE is read only. 
0 = Idle. ANIN2 input voltage is read only. 
1 = Dual gain. External jumper connection between the analog 
inputs is required.  
2 = Current limit mode. Second analog input limits current 
command.
