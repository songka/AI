# 機構2D自動報價系統 — 異常處理策略設計

日期：2026-08-01
版本：V1.0

---

## 一、異常分級

| 級別 | 標記 | 含義 | 系統行為 |
|---|---|---|---|
| **FATAL** | 🔴 | 系統無法繼續 | 終止當前報價，輸出錯誤日誌 |
| **ERROR** | 🟠 | 當前零件無法報價 | 標記為 U，記錄到未知項清單，繼續下一個零件 |
| **WARNING** | 🟡 | 可報價但有風險 | 繼續報價，降低信心度，記錄警告 |
| **INFO** | 🔵 | 資訊提示 | 不影響報價，記錄到日誌 |

---

## 二、各階段異常處理

### 2.1 文件讀取階段

| 異常 | 級別 | 處理 |
|---|---|---|
| 文件不存在 | ERROR | 跳過該文件，記錄路徑 |
| 文件格式不支援 (.png/.jpg) | ERROR | 跳過，提示支援格式清單 |
| 文件損壞/無法開啟 | ERROR | 跳過，記錄異常訊息 |
| 文件大小超過上限 (>50MB) | WARNING | 嘗試解析，記錄警告 |
| 目錄為空 | WARNING | 輸出空結果，提示無圖紙 |
| 中文路徑/特殊字符 | INFO | 正常處理（已支援 UTF-8） |

### 2.2 DWG/DXF 解析階段

| 異常 | 級別 | 處理 |
|---|---|---|
| DWG 版本不支援 | ERROR | 標記 parse_status=FAILED，提示安裝新版 ODA |
| ODA 轉換失敗 | ERROR | 記錄原始錯誤，生成 Issue |
| DXF 解析異常 (語法錯誤) | ERROR | 標記 parse_status=FAILED |
| 不支援的 Entity 類型 | WARNING | 跳過該 entity，記錄類型，繼續解析 |
| 部分 Entity 解析失敗 | WARNING | parse_status=PARTIAL，記錄失敗清單 |
| TEXT 編碼異常 (亂碼) | WARNING | 保留原始 bytes，嘗試多編碼解碼 |

### 2.3 特徵提取階段

| 異常 | 級別 | 處理 |
|---|---|---|
| 無法提取外形尺寸 | ERROR | 標記 dimension_missing，無法計算材料費 |
| 材料文字缺失 | WARNING | 嘗試從文件名和 BOM 推測，標記 material_unknown |
| 材料文字模糊 (多候選) | WARNING | AI 分析候選，人工確認 |
| 表面處理文字缺失 | WARNING | 假設無表面處理，標記待確認 |
| 公差標註無法解析 | INFO | 記錄原始文字 |

### 2.4 規則匹配階段

| 異常 | 級別 | 處理 |
|---|---|---|
| 材料無匹配規則 | WARNING | 標記為 U，觸發 AI 建議 |
| 材料規則 status=PENDING | WARNING | 標記為 U，提示價格待確認 |
| 表面處理無匹配規則 | WARNING | 標記為 U |
| 多個規則候選 | WARNING | 選擇最佳匹配，記錄候選清單 |
| 規則版本過期 | INFO | 使用最新有效版本 |

### 2.5 價格計算階段

| 異常 | 級別 | 處理 |
|---|---|---|
| 密度數據缺失 | ERROR | 無法計算重量→材料費，標記 U |
| 體積計算異常 (負值) | ERROR | 標記計算異常 |
| 表面積無法計算 (噴塗計價) | WARNING | 使用估算值，降低信心度 |
| 單價為 0 (PENDING) | WARNING | 標記 U，記錄待確認 |
| 計算結果與歷史價格偏差 >30% | WARNING | 生成 Issue，提示人工覆核 |

## 三、降級策略鏈

```
正常流程:  規則引擎(C) → 歷史匹配(H) → 行業參考(E) → AI建議(AI/M) → 人工確認(M)

降級規則:
  C 命中 + 信心度 HIGH    → 直接輸出 ✅
  C 命中 + 偏差 >30%       → 降級到 H 對比，生成 WARNING Issue
  C 未命中                  → 降級到 H (歷史相似度搜尋)
  H 未命中                  → 降級到 E (行業參考)
  E 未命中                  → 降級到 AI (文字分析+建議)
  AI 無法判斷               → 標記 U (未知)，進入人工確認隊列
```

## 四、重試策略

| 場景 | 策略 |
|---|---|
| ODA 轉換失敗 | 不重試（二進制格式問題不會自動修復） |
| DXF 解析異常 | 不重試（文件內容問題） |
| 網絡請求失敗 (AI API) | 重試 3 次，指數退避 (1s/2s/4s) |
| 數據庫鎖定 | 重試 3 次，每次等待 500ms |

## 五、未知項標記流程

```
發現未知項
    │
    ▼
生成 Issue (severity=UNKNOWN, status=OPEN)
    │
    ▼
記錄到報價單「未知項」Sheet
    │
    ▼
如果有 AI 可用 → 調用 AI 分析 → 記錄 ai_suggestion
    │
    ▼
人工審核未知項清單
    ├── 確認 → status=RESOLVED, source=M
    ├── 修改 → resolution=人工填寫的修正
    └── 跳過 → 報價中該項金額為 0，標記為 U
```

## 六、異常日誌格式

```json
{
  "timestamp": "2026-08-01T10:30:00",
  "level": "WARNING",
  "stage": "feature_extraction",
  "drawing_id": "dwg-001",
  "code": "MATERIAL_NOT_FOUND",
  "message": "材料文字 '6061鋁' 未匹配任何標準材料",
  "raw_input": "6061鋁",
  "suggestions": ["A6061-T6 (confidence=0.85)", "A5052 (confidence=0.15)"],
  "resolution": null
}
```

## 七、全局異常處理原則

1. **永不放棄整個批次**：單個文件失敗不影響其他文件
2. **所有異常可追溯**：記錄 source_file + source_row + drawing_id
3. **默認安全**：無法判斷時標記 U，不猜價格
4. **AI 僅作建議**：AI 建議標記為 AI/M，需人工確認
5. **不吞異常**：所有異常寫入日誌 + IssueReport
