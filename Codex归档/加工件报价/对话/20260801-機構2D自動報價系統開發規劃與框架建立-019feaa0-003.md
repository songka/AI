========================
重要分類修正
========================

注意：

BOM中的：

- 機構外購件
- 電控外購件

只是歷史資料分類。

不能直接映射為 CAD 報價分類。


未來實際輸入主要是：

PDF / DWG

因此：

CAD Feature 必須根據圖紙結構判斷。


例如：

以下零件：

- 把手
- 合頁
- 磁吸
- 角碼
- 螺絲附件


如果屬於防護門/機架結構：

應視為：

「結構附件」

而不是：

獨立外購件報價。


禁止新增：

PurchasedComponentFeature


========================
新增 Feature 類型
========================


1. StructureAssemblyFeature

用途：

表示設備結構模組。


例如：

- 防護罩
- 防護圍欄
- 機架
- 門模組


字段：

- assembly_type
- component_list
- source
- confidence


示例：

{
"type":"STRUCTURE_ASSEMBLY",

"name":"防護圍欄",

"confidence":0.9
}



------------------------


2. FrameFeature

用途：

型材框架。


字段：

- profile_type
- material
- total_length
- joint_count
- connection_type
- confidence


例如：

鋁型材框架：

{
"type":"FRAME",

"profile_type":"鋁型材",

"joint_count":20
}



------------------------


3. SheetMetalFeature

用途：

鈑金結構。


字段：

- material
- thickness
- bend_count
- cutting_length
- surface_treatment
- confidence


報價影響：

- 雷切
- 折彎
- 焊接
- 表面處理



------------------------


4. AcrylicFeature

用途：

透明件。


字段：

- material
- thickness
- area
- color
- confidence


例如：

白色透明亞克力。



------------------------


5. StructureAccessoryFeature

用途：

結構附件。


不是獨立外購件。

例如：

- 合頁
- 把手
- 磁吸
- 角碼
- 門鎖


字段：

- category
- items
- quantity
- source
- confidence


示例：

{
"type":"STRUCTURE_ACCESSORY",

"category":"DOOR_HARDWARE",

"items":[
"合頁",
"磁吸",
"把手"
]
}


報價歸屬：

Structure Assembly。


------------------------


6. WeldingFeature

用途：

焊接結構。


字段：

- weld_length
- joint_count
- weld_type
- source
- confidence
