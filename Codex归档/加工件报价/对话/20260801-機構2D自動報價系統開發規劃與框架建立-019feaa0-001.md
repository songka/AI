開發 BOM Excel Reader 前，請先確認以下要求：

1. 不要假設固定 Excel 欄位位置。

BOM Reader 必須支持：
- Sheet名稱變化
- 欄位名稱映射
- 中文欄位
- 空白行
- 合併單元格
- 多層BOM


2. 建立 BOM 欄位映射配置。

新增：

config/bom-column-mapping.yaml

例如：

item:
  - Item
  - 料號
  - 零件號

description:
  - Description
  - 描述
  - 品名


3. BOM Reader 輸出必須包含：

- source_file
- source_sheet
- source_row

確保每筆資料可追溯。


4. 讀取後不要立即報價。

流程：

Excel
 ↓
BomSheet
 ↓
ParsedPart
 ↓
分類
 ↓
後續Rule Engine

- 多Sheet

- 修改文件列表

- pytest結果
