## 用户

補充重大企業部署需求。

目前確認：

1. 所有使用者訪問同一個 SMB 共享盤。
2. SMB 權限全部為可讀寫。
3. 因此不能依靠 Windows 文件權限管理角色。
4. 軟件內必須建立獨立帳號、密碼、角色、權限管理系統。


請在開始後續開發前，先更新設計文件，不開發功能。

多台 Windows Client

同一 SMB共享資料夾

本地Cache

報價程序

多人直接操作同一SQLite文件。
