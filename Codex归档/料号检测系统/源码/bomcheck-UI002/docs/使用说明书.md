# BOMCheck 料号检测系统使用说明书

适用版本：`bomcheck-UI002`  
编写日期：2026-06-30

## 1. 系统用途

BOMCheck 用于检查 BOM Excel 中的料号问题，主要帮助完成：

- 检查失效料号。
- 自动写入替换料号/描述。
- 统计绑定料号需求。
- 判断必备料号是否缺少。
- 统计重要物料。
- 查询系统料号库。
- 维护失效料号库、绑定料号库、重要物料、屏蔽申请人、料号资源和账号权限。

## 2. 启动方式

### 方式一：运行桌面版

源码运行：

```bat
cd /d D:\Codex项目\料号检测系统\bomcheck-UI002
python app.py
```

如果已打包：

```text
双击 dist\bomcheck\bomcheck.exe
```

注意：如果使用 exe，必须确认 exe 是根据当前源码重新打包的版本，否则窗口优化不会生效。

### 方式二：运行 Web 版

```bat
cd /d D:\Codex项目\料号检测系统\bomcheck-UI002
uvicorn app_web:app --host 0.0.0.0 --port 8000
```

本机访问：

```text
http://127.0.0.1:8000/
```

局域网访问：

```text
http://服务器IP:8000/
```

健康检查：

```text
http://服务器IP:8000/health
```

## 3. 桌面版使用流程

### 3.1 登录

1. 打开桌面版。
2. 如需维护数据或账号，点击登录。
3. 使用管理员账号登录。

默认账号通常为：

```text
admin / admin
```

首次使用后建议立即修改密码。普通用户不应使用管理员账号；管理员账号仅用于配置、资料维护和权限管理。

### 3.2 执行 BOM 检测

1. 进入“BOM 执行”页面。
2. 点击“浏览”，选择待检测的 BOM Excel 文件。
3. 点击“开始执行”。
4. 等待结果区输出处理结果。
5. 根据提示查看是否存在失效料号、缺料或重要物料命中。

建议：

- 执行前关闭正在编辑的同名结果文件，避免保存冲突。
- BOM 文件建议使用 `.xlsx` 或 `.xlsm`。

### 3.3 查看料号查询

1. 进入“料号查询”页面。
2. 输入料号、描述或申请人关键词。
3. 查看匹配结果。
4. 可打开料号详情，查看系统信息和资源文件。

### 3.4 配置管理

进入“配置管理”页面，可维护：

- 数据文件路径。
- 失效料号库。
- 绑定料号库。
- 重要物料。
- 屏蔽申请人。
- 料号资源。
- 账号权限。

无权限的入口会隐藏或不可用。

## 4. 失效料号库维护

入口：桌面版“配置管理” -> “失效料号库”

用途：

- 维护已经失效的料号。
- 维护替换料号和替换描述。

字段说明：

- 失效料号：BOM 中需要查找的旧料号。
- 失效描述：旧料号说明。
- 替换料号：建议替换的新料号。
- 替换描述：新料号说明。

操作说明：

1. 打开“失效料号库”。
2. 使用上方表格查看已有记录。
3. 点击“新增”添加一条记录。
4. 在下方字段区填写料号和描述。
5. 可使用搜索框筛选记录。
6. 点击“保存”写回 Excel。

窗口说明：

- 当前版本已支持弹窗内部滚动。
- 表格底部有横向滚动条，列显示不全时可左右拖动。

## 5. 绑定料号库维护

入口：桌面版“配置管理” -> “绑定料号”

用途：

- 定义项目主料号。
- 定义每个项目下的必备料号分组。
- 定义每个分组下的可选料号和需求数量。
- 支持条件模式判断。

常见字段：

- 项目描述：便于识别项目。
- 索引料号：用于匹配 BOM 中的主料号。
- 分组名称：如驱动器、线材、模块等。
- 数量：该分组需要的数量。
- 可选料号：满足该分组需求的料号候选。
- 条件模式：控制该可选料号是否在特定条件下生效。

操作说明：

1. 选择左侧项目。
2. 编辑项目描述、索引料号、索引描述。
3. 选择或新增需求分组。
4. 在可选料号表格中添加料号、描述、条件和数量。
5. 点击保存。

## 6. 料号资源维护

入口：桌面版“配置管理” -> “料号资源维护”

用途：

- 给料号维护模型文件。
- 维护本地地址和网络地址。
- 维护图片列表。
- 预览图片。
- 自动生成或批量生成料号资源。

操作说明：

1. 左侧选择已有料号，或点击新增。
2. 填写料号。
3. 选择模型文件。
4. 填写本地地址、网络地址。
5. 添加图片。
6. 选择图片后可在右侧预览。
7. 点击“保存资源”。

自动生成资源：

1. 在“料号列表”中输入料号，每行一个。
2. 点击“加入队列”。
3. 点击“开始生成”。
4. 系统会先检查资源目录和进度文件是否可写，确认后开始生成。
5. 观察进度列表，运行中会显示当前料号、已运行时间和当前阶段。
6. 如需中断，点击“终止生成”。当前网络请求会等待超时返回，随后可选择保留或撤销本次已生成内容。

窗口说明：

- 当前版本已支持主内容区横向/纵向滚动。
- 图片列表有独立滚动条。
- 如果窗口仍显示不全，可拖动底部或右侧滚动条查看。
- 自动生成依赖网络搜索，若单个料号长时间停留在“搜索官网”或“搜索图片”，可点击“终止生成”；系统会在网络超时后返回并进入终止确认。
- 自动生成结束后请抽查图片和链接，确认资料与料号一致后再正式使用。

## 7. 重要物料维护

入口：桌面版“配置管理” -> “重要物料”

规则：

- 每行一个关键词。
- 执行 BOM 检测时，系统按关键词统计重要物料命中。
- 支持简繁转换匹配。

操作：

1. 打开重要物料维护。
2. 每行填写一个关键词。
3. 点击保存。

## 8. 屏蔽申请人维护

入口：桌面版“配置管理” -> “屏蔽申请人”

规则：

- 每行一个申请人名称或关键字。
- 用于过滤不需要参与统计或展示的数据。

操作：

1. 打开屏蔽申请人维护。
2. 每行填写一个申请人。
3. 点击保存。

## 9. Web 版使用

### 9.1 首页执行 BOM

1. 打开 Web 首页。
2. 上传 BOM Excel。
3. 点击开始执行。
4. 跳转到任务页面查看状态。
5. 任务完成后下载结果文件。

### 9.2 查询料号

访问：

```text
/query
```

说明：

- 不需要登录。
- 首次打开不会加载全库。
- 输入关键词后查询。
- 如需查看全库，点击“显示全部”或访问：

```text
/query?show_all=1
```

### 9.3 管理页面

访问：

```text
/admin
```

需要管理员登录。可维护：

- 配置文件。
- 失效料号库。
- 绑定料号库。
- 重要物料。
- 屏蔽申请人。
- 用户账号。

## 10. 配置文件

配置文件：`config.json`

常用字段：

```json
{
  "invalid_part_db": "失效料号.xlsx",
  "binding_library": "绑定料号.js",
  "important_materials": "重要物料.txt",
  "system_part_db": "系统料号.xlsx",
  "blocked_applicants": "屏蔽申请人.txt",
  "part_asset_dir": "料号资源",
  "asset_unc_prefix": "",
  "asset_local_prefix": "",
  "account_store": "accounts.json",
  "ua_lookup_dir": ""
}
```

说明：

- 相对路径以配置文件所在目录为基准。
- 网络共享路径需要保证当前电脑有访问权限。
- Web 账号库固定使用 `data/accounts.json`。

## 11. 打包说明

如需生成 Windows exe：

```bat
cd /d D:\Codex项目\料号检测系统\bomcheck-UI002
scripts\build_windows_exe.bat
```

如果 `python` 命令不可用，可先指定真实 Python 路径：

```bat
set BOMCHECK_PYTHON=C:\Path\To\python.exe
scripts\build_windows_exe.bat
```

打包成功后查看：

```text
dist\bomcheck\bomcheck.exe
```

交付建议：

- 分发整个 `dist\bomcheck` 文件夹。
- 同步确认配置文件和数据文件路径。
- 在目标电脑上打开失效料号库、料号资源维护窗口，确认窗口显示正常。

## 12. 常见问题

### 12.1 窗口还是显示不全

处理：

1. 确认运行的是最新源码或最新打包 exe。
2. 尝试拖动窗口右侧和底部滚动条。
3. 对于表格，查看表格底部是否有横向滚动条。
4. 如使用 exe，重新打包。

### 12.2 配置文件读取失败

处理：

1. 检查 `config.json` 是否存在。
2. 检查路径是否正确。
3. 检查共享盘是否可访问。
4. 检查文件是否被占用或无权限读取。

### 12.3 Excel 保存失败

处理：

1. 关闭正在打开的结果 Excel。
2. 检查输出目录权限。
3. 换一个本地目录测试。

### 12.4 查询无结果

处理：

1. 检查系统料号库路径。
2. 检查系统料号库是否已生成或更新。
3. 尝试使用更短关键词。
4. 检查是否被屏蔽申请人规则过滤。

### 12.5 Web 版无法登录

处理：

1. 检查 `data/accounts.json` 是否存在。
2. 使用管理员账号登录。
3. 如账号库损坏，可从备份恢复或重新初始化。

## 13. 使用注意事项

- 修改数据文件前建议备份。
- 不建议多人同时编辑同一个失效料号库或绑定料号库。
- Web 服务运行在共享盘路径时，不建议使用 `--reload`。
- 每次源码修改后，如使用 exe，都需要重新打包。
