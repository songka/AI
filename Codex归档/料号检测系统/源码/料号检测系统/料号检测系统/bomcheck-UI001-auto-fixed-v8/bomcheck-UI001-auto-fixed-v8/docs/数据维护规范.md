# BOMCheck 数据维护规范

适用版本：`bomcheck-UI001-auto-fixed-v8-r1`  
编写日期：2026-06-29

## 1. 通用要求

1. 修改任何业务数据文件前必须备份。
2. 同一时间只允许一名维护者编辑同一个核心数据文件。
3. 保存后必须重新执行一次查询或 BOM 样本验证，确认维护结果生效。
4. 不建议直接在共享盘中多人同时打开同一个 Excel 或 JSON 文件。

推荐备份命名：

```text
文件名_YYYYMMDD_HHMM_维护人
```

示例：

```text
失效料号_20260629_0930_张三.xlsx
绑定料号_20260629_0930_张三.js
```

## 2. 失效料号库

维护对象：`失效料号.xlsx`

字段要求：

| 字段 | 要求 |
| --- | --- |
| 失效料号 | 必填，不允许重复 |
| 失效描述 | 建议填写，便于人工复核 |
| 替换料号 | 有替代料时填写 |
| 替换描述 | 有替代料时建议填写 |

维护后检查：

1. 保存时确认没有空料号和重复料号。
2. 用包含该失效料号的 BOM 样本执行检测。
3. 确认结果文件中写入替换料号和替换描述。

## 3. 绑定料号库

维护对象：`绑定料号.js`

关键字段：

| 字段 | 要求 |
| --- | --- |
| 项目描述 | 建议填写，便于识别项目 |
| 索引料号 | 建议填写，用于匹配 BOM 主料号 |
| 索引描述 | 索引料号为空时应填写，用于描述匹配 |
| 分组名称 | 必填 |
| 分组数量 | 必须大于 0 |
| 可选料号 | 必填 |
| 条件模式 | 只能为 `ALL`、`ANY`、`NOTANY` 或留空 |
| 条件料号 | 设置条件模式时必须填写 |
| 数量 | 填写时必须大于 0 |

条件模式说明：

| 模式 | 含义 | 示例 |
| --- | --- | --- |
| `ALL` | 条件料号全部存在时生效 | BOM 同时包含 A、B 时才要求 C |
| `ANY` | 条件料号任意一个存在时生效 | BOM 包含 A 或 B 时要求 C |
| `NOTANY` | 条件料号全部不存在时生效 | BOM 不包含 A、B 时要求 C |

维护后检查：

1. 保存前确认规则库已备份。
2. 用包含索引料号的 BOM 样本执行检测。
3. 确认缺料、可用数量和剩余物料统计符合预期。

## 4. 重要物料

维护对象：`重要物料.txt`

规则：

1. 每行一个关键词。
2. 不要填写空行或重复关键词。
3. 关键词不宜过长，避免误粘贴整列内容。
4. 系统会进行简繁处理，提高简体和繁体混用时的匹配能力。

维护后检查：

1. 用包含关键词的 BOM 样本执行检测。
2. 确认结果中“重要物料”统计命中。

## 5. 屏蔽申请人

维护对象：`屏蔽申请人.txt`

规则：

1. 每行一个申请人名称或关键字。
2. 不要填写空行或重复项。
3. 修改后需要重新查询系统料号，确认过滤结果符合预期。

维护后检查：

1. 查询一个原本会命中的申请人数据。
2. 确认屏蔽规则生效后不再展示或不再参与统计。

## 6. 料号资源

维护对象：`料号资源/`

建议：

1. 每个料号使用独立目录。
2. 图片文件建议使用清晰可辨的名称，避免只保留临时下载名。
3. 模型文件、本地地址、网络地址修改后应立即打开验证。
4. 自动生成资源后，应抽查图片和链接是否对应正确料号。

## 7. 异常处理

| 场景 | 处理 |
| --- | --- |
| 保存失败 | 检查文件是否被 Excel 或其他程序打开占用 |
| 查询无结果 | 检查系统料号库路径、关键词和屏蔽申请人规则 |
| Web 无法登录 | 检查 `data/accounts.json` 是否存在且未损坏 |
| 共享盘不可访问 | 先确认当前电脑网络权限，再检查 `config.json` |
| 规则保存后结果异常 | 恢复最近一次备份，并记录异常样本 |
