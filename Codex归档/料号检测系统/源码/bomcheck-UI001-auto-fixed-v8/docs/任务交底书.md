编写日期：2026-06-29

## 1. 项目概况

BOMCheck 是用于 BOM Excel 检测、料号查询和数据维护的本地工具。当前版本包含两套入口：

- 桌面版：`app.py`，基于 Tkinter，适合单机或共享盘环境直接运行。
- Web 版：`app_web.py`，基于 FastAPI + Jinja2，适合局域网浏览器访问。

两套入口复用 `bomcheck_app/` 中的业务逻辑，核心处理能力包括：

- 检查 BOM 中的失效料号，并按失效料号库写入替换料号/描述。
- 识别数量列，统计料号数量。
- 按绑定料号库计算必备料号需求、缺料项和多选组合。
- 按重要物料关键词统计命中情况。
- 生成处理后的 Excel 结果文件。
- 查询系统料号库、查看料号资源、维护失效料号库/绑定料号库/重要物料/屏蔽申请人/账号权限。

## 2. 当前目录结构

主要目录和文件如下：

- `app.py`：桌面版主程序。
- `app_web.py`：Web 版主程序。
- `bomcheck_app/`：业务逻辑模块，包括配置、账号、Excel 处理、系统料号、资源管理、爬取等。
- `templates/`：Web 版 Jinja2 页面模板。
- `static/app.css`：Web 版样式。
- `scripts/build_windows_exe.bat`：Windows 打包脚本。
- `scripts/crawl_part_assets.py`：批量生成料号资源脚本。
- `config.json`：数据源路径配置。
- `失效料号.xlsx`：失效料号数据库。
- `绑定料号.js`：绑定料号/必备料号规则库。
- `重要物料.txt`：重要物料关键词库。
- `屏蔽申请人.txt`：屏蔽申请人列表。
- `料号资源/`：料号图片、模型、链接等资源索引目录。

运行时目录：

- `data/uploads/`：Web 上传临时文件。
- `data/results/`：Web 处理结果临时文件。
- `data/accounts.json`：Web 本地账号库。
- `app_web.log`：Web 日志。

## 4. 关键业务规则

### 失效料号处理

- 读取失效料号库。
- 在 BOM 中查找命中的失效料号。
- 命中行会被标记，并在结果中写入替换料号和替换描述。
- 如果存在替换料号，后续数量统计和绑定料号计算会使用替换后的料号。

### 数量列识别

- 程序会跳过前几列说明性字段。
- 在后续列中寻找更像数量列的数字列。
- 识别结果会影响缺料统计，现场验收时需用典型 BOM 测试。

### 绑定料号/必备料号

绑定料号库使用 JSON 结构，核心字段：

- `projectDesc`：项目描述。
- `indexPartNo`：索引料号/项目主料号。
- `indexPartDesc`：索引料号描述。
- `requiredGroups`：必备料号分组。
- `choices`：每个分组内可选料号。
- `conditionMode`：条件模式，如 `ALL`、`ANY`、`NOTANY`。
- `conditionPartNos`：条件料号列表。
- `number`：需求数量。

### 重要物料

- 每行一个关键词。
- 支持简繁处理，提高繁体/简体混用时的匹配能力。

### 屏蔽申请人

- 屏蔽申请人列表用于过滤或排除特定申请人相关数据。
- 具体效果取决于当前系统料号处理逻辑和配置。

## 5. 配置文件说明

`config.json` 控制数据文件路径。常用字段：

```json
{
  "invalid_part_db": "失效料号.xlsx",
  "binding_library": "绑定料号.js",
  "important_materials": "重要物料.txt",
  "system_part_db": "系统料号.xlsx",
  "blocked_applicants": "屏蔽申请人.txt",
  "part_asset_dir": "料号资源",
  "asset_unc_prefix": "",
  "asset_local_prefix": "",
  "account_store": "accounts.json",
  "ua_lookup_dir": ""
}
```

注意：

- 相对路径按配置文件所在目录解析。
- 桌面版默认优先读取代码中配置的网络配置路径，也可通过环境变量 `BOMCHECK_CONFIG` 指定。
- Web 版同样支持 `BOMCHECK_CONFIG`。
- Web 账号库固定写入本地 `data/accounts.json`。

## 6. 运行方式

### 桌面版源码运行

```bat
cd /d D:\Codex项目\料号检测系统\bomcheck-UI001-auto-fixed-v8
pip install -r requirements.txt
python app.py
```

### Web 版源码运行

```bat
cd /d D:\Codex项目\料号检测系统\bomcheck-UI001-auto-fixed-v8
pip install -r requirements.txt
uvicorn app_web:app --host 0.0.0.0 --port 8000
```

局域网访问时使用服务器 IP，例如：

```text
http://服务器IP:8000/
```

### 打包 Windows exe

```bat
cd /d D:\Codex项目\料号检测系统\bomcheck-UI001-auto-fixed-v8
scripts\build_windows_exe.bat
```

输出位置：

```text
dist\bomcheck\bomcheck.exe
```

交付时建议分发整个 `dist\bomcheck` 目录，并确认配置文件和数据文件路径可访问。

## 7. 验收建议

### 桌面版验收

1. 启动 `python app.py` 或打包后的 `bomcheck.exe`。
2. 不最大化窗口，检查主界面是否可通过滚动看到完整内容。
3. 打开“失效料号库”，确认：
   - 窗口不超出屏幕。
   - 表格可横向滚动。
   - 保存/重新载入/关闭按钮可见或可滚动到。
4. 打开“料号资源维护”，确认：
   - 左侧料号列表可滚动。
   - 右侧图片列表和预览不遮挡底部区域。
   - 自动生成区域可滚动到所有按钮。
5. 选择一份测试 BOM 执行，确认结果区正常输出。

### Web 版验收

1. 启动 Web 服务。
2. 打开首页，非最大化浏览器窗口下检查上传区、快速查询区是否完整显示。
3. 打开 `/query`，检查查询表单按钮是否换行/可见。
4. 打开 `/query?show_all=1&size=8`，检查表格可横向滚动。
5. 登录管理员，检查配置页、失效料号页、绑定料号页、用户管理页。

## 9. 风险点

- 网络共享盘不可访问时，配置文件或业务库读取会失败。
- Excel 文件被用户打开占用时，保存结果可能失败。
- 失效料号库、绑定料号库结构不规范时，统计结果会异常。
- 文档编码或目标电脑编辑器设置异常时，仍可能出现中文显示问题，正式分发前需现场复核。
- 打包后的 exe 不会自动包含源码最新修改，必须重新打包。
