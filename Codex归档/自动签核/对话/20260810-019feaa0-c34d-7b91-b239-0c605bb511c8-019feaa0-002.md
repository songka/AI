## 交付文件

### 技能包 `.claude/auto-sign/`

| 文件 | 说明 |
|------|------|
| `CLAUDE.md` | **交付文档** — 完整架构、规则系统、操作符、通知接口、扩展指南 |
| `cli.py` | CLI（12个命令含 notify） |
| `auto_sign.py` | 核心引擎 |
| `rules.py` | 规则引擎（18个操作符 + zhconv 简体检测） |

### 当前规则

```
拒签优先: 简体字/空描述
         + 半成品;軟體 条件不满足(单位/类别/R版本)
         + 原材料;電控外購件 条件不满足(单位/类别)

签核其次: content_whitelist 开头 + whitelist 白名单

通知:    (规则已预留，在 rules.json 的 notify 数组中添加即可)
```

### 通知系统

```bash
py cli.py notify                              # 控制台通知
py cli.py notify -c webhook --webhook-url "..." # Webhook 通知
py cli.py notify -c "console,webhook" --webhook-url "..."  # 多渠道
```

后续 AI 可根据 `CLAUDE.md` 直接修改 `rules.json` 添加规则，或在 `notify.py` 注册新通知渠道。
