# CLI 签核工具箱 - 实施计划

## Context

现有 `auto_sign.py` 是一个全自动脚本：登录 → 读取页面 → 根据白名单/黑名单判断 → 自动提交。用户需要一个**交互式/手动控制的 CLI 工具箱**，把各个功能拆成独立子命令，可以手动选择签核或拒签哪些项目。自动判断逻辑（白名单/黑名单）暂时不管。

## 目标

构建一个 CLI 工具箱，支持以下子命令：

| 命令 | 功能 |
|------|------|
| `login` | 登录并验证成功，保存 session 状态 |
| `list` | 列出待签核项目，显示编号、申请人、描述、时间等 |
| `show <id>` | 查看单个项目详细信息 |
| `approve <id...>` | 签核指定编号的项目 |
| `reject <id...>` | 拒签指定编号的项目 |
| `approve-all` | 签核所有待处理项目 |
| `reject-all` | 拒签所有待处理项目 |

额外的全局选项：
- `--config` 指定配置文件
- `--dry-run` 只输出不提交

## 设计决策

### CLI 框架：argparse subcommands（标准库，零额外依赖）

使用 `argparse` 的 `add_subparsers()` 实现子命令，与现有代码风格一致，不需要新增依赖。

### 架构

```
auto_sign.py (现有，保留全自动模式)
cli.py        (新增，CLI 工具箱)
```

`cli.py` 复用 `auto_sign.py` 中的核心函数：
- `load_config()` - 读取配置
- `create_session()` - 创建 HTTP 会话
- `login()` - 登录
- `fetch_sign_page()` - 获取签核页面
- `parse_applications()` - 解析申请列表
- `parse_html()` - HTML 解析
- `collect_form_payload()` / `set_payload_value()` / `add_submit_action()` / `find_submit_form()` / `form_action_url()` - 表单操作
- `request_html()` - HTTP 请求
- `extract_record_fields()` / `record_signature()` - 记录签名
- `Application` / `Decision` dataclasses

### 需要新增/修改的功能

#### 1. 解析增强 - 同时找到 Approve 和 Reject 单选按钮

当前 `Application` dataclass 只存储了 approve 的 radio 信息。需要扩展为同时存储 approve 和 reject 的 radio。

在 `parse_applications()` 中，每行需要找到两个 radio：
- Approve radio: 当前已有 (`input.passSelectAll_N[type='radio']`)
- Reject radio: 需要新增，常见命名如 `input.rejectSelectAll_N[type='radio']`

命名为 `Application.radio_approve_name/value` 和 `Application.radio_reject_name/value`。

#### 2. 提交逻辑 - 支持签核和拒签

将 `submit_approvals()` 重构为通用的 `submit_decisions()`，接受 action 参数（'approve' 或 'reject'），根据 action 设置对应的 radio 值。

#### 3. CLI 子命令

**`login`**
- 创建 session，执行登录
- 打印登录结果（成功/失败）
- 可选：验证后列出待签核数量

**`list`**
- 获取签核页面
- 解析所有申请
- 以表格形式打印：编号、申请人、描述、单位、类别、时间

**`show <id>`**
- 获取签核页面
- 显示指定编号项目的完整原始信息

**`approve <id...>`**
- 支持单个或多个编号，如 `approve 1 3 5`
- 支持范围，如 `approve 1-5`
- 提交时只勾选指定项目的 approve radio
- 记录到 Excel

**`reject <id...>`**
- 同上，但勾选 reject radio

**`approve-all`**
- 签核所有待处理项目

**`reject-all`**
- 拒签所有待处理项目

#### 4. 记录增强

`record_signature()` 增加 `action` 字段，记录是"签核"还是"拒签"。

### 打印格式

`list` 命令输出表格：

```
用法:
  python cli.py login              登录并查看待签数量
  python cli.py list               表格列出所有待签项目
  python cli.py show 3             查看第3项完整信息
  python cli.py approve 1 3 5-7   签核第1,3,5,6,7项
  python cli.py reject 2 4         拒签第2,4项
  python cli.py approve-all        全部签核
  python cli.py reject-all         全部拒签

全局选项:
  --config config.json   指定配置文件
  --dry-run              预览操作，不实际提交
```

- ID 范围支持：`1-5` 自动展开为 1,2,3,4,5

## rules.json 格式 — AND/OR 多维条件

```json
{
  "auto_approve": [
    {
      "name": "张三的PH类",
      "conditions": [
        {"field": "申请人", "op": "contains", "value": "张三"},
        {"field": "类别", "op": "equals", "value": "PH"}
      ],
      "logic": "AND"
    },
    {
      "name": "原材料或半成品",
      "conditions": [
        {"field": "描述", "op": "contains", "value": "原材料"},
        {"field": "描述", "op": "contains", "value": "半成品"}
      ],
      "logic": "OR"
    }
  ],
  "auto_reject": [
    {
      "name": "黑名单人员",
      "conditions": [
        {"field": "申请人", "op": "in_blacklist", "value": ""}
      ],
      "logic": "AND"
    }
  ],
  "notify": [
    {
      "name": "新类别需确认",
      "conditions": [
        {"field": "类别", "op": "not_in_list", "value": "PH,ST,RAW"}
      ],
      "logic": "AND"
    }
  ]
}
```

### 支持的操作符
- `equals` — 精确匹配
- `contains` — 包含（大小写不敏感）
- `starts_with` — 以...开头
- `regex` — 正则匹配
- `in_list` — 在逗号分隔列表中
- `not_in_list` — 不在列表中
- `in_whitelist` — 命中白名单文件
- `in_blacklist` — 命中黑名单文件

### 规则匹配逻辑
1. `auto_approve` 规则组：按顺序匹配，第一组命中即标记 `approve`
2. `auto_reject` 规则组：命中即标记 `reject`（优先级高于 approve）
3. `notify` 规则组：命中即标记 `notify`（需人工确认）
4. 以上都不匹配：留空，用户手动填写

```
.claude/auto-sign/          ← 整体复制给他人即可用
  cli.py                    ← CLI 工具箱

  config.example.json       ← 配置模板（无凭证）
  rules.example.json        ← 规则模板
  skill.md                  ← 技能文档

  cli.py, auto_sign.py      ← 薄包装入口

  auth.json                 ← 账号密码（自动生成，已 gitignore）
  rules.json                ← 用户规则（从 example 复制）
  pending_signs.xlsx        ← fetch 产出
  sign_records.xlsx         ← 签核记录
```

### 工作流

```
# 1. 定时抓取（Windows 任务计划 / crontab）
python cli.py fetch
  → 生成 pending_signs.xlsx
    - 自动分类统计
    - 规则自动预填操作列
    - 数据验证下拉（approve/reject/skip）
    - 统计摘要 sheet

# 2. 用户打开 Excel，检查并补填「操作」列

# 3. 批量执行
python cli.py process
  → 按操作列逐项签核/拒签
  → 更新处理状态
```

### 新增命令

| 命令 | 功能 |
|------|------|
| `fetch` | 抓取待签 → 生成 Excel，自动分类 + 规则预匹配 |
| `process` | 读取 Excel → 批量签核/拒签 |
| `run` | 一条龙：fetch → 等待编辑 → process |

### rules.json 多维条件

```json
{
  "auto_approve": [{"name": "...", "conditions": [...], "logic": "AND|OR"}],
  "auto_reject":  [...],
  "notify":       [...]
}
```

支持 8 种操作符：`equals`, `contains`, `starts_with`, `regex`, `in_list`, `not_in_list`, `in_whitelist`, `in_blacklist`。`auto_reject` 优先级最高，`notify` 标记需人工确认项。
