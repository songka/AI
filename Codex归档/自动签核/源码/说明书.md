# 签核自动工具箱 — 使用说明书

## 1. 系统概述

无浏览器依赖的 HTTP 自动签核系统，用于 GSC 签核平台 (`gsc.getac.com/signs/l1/W`)。

**核心能力：** 定时抓取 → 规则自动判断 → Excel 离线决策 → 批量签核/拒签 → 通知。

---

## 2. 环境部署

### 2.1 复制技能包

将 `.claude/auto-sign/` 目录整体复制到目标机器。

### 2.2 首次运行

直接运行任意命令，依赖自动安装（`requests`, `beautifulsoup4`, `openpyxl`, `zhconv`）：

```bash
py cli.py --help
```

### 2.3 配置

```bash
cp config.example.json ../../config.json    # 编辑 URL、超时等
cp rules.example.json ../../rules.json      # 编辑规则（可选）
```

`config.json` 内容：
```json
{
  "url": "https://gsc.getac.com/signs/l1/W",
  "verify_ssl": false,
  "timeout": 30,
  "dry_run": false,
  "submit_when_no_approvals": false
}
```

### 2.4 首次登录

```bash
py cli.py login
```

输入账号密码后自动保存到 `auth.json`（与配置文件分离，不会被复制泄露）。

## 3. 日常使用

### 3.1 查看待签

```bash
py cli.py list
```

输出简洁表格：**# | 申请人 | 描述** + 分类统计。

### 3.2 测试规则（推荐先跑）

```bash
py cli.py fetch --dry-run
```

逐项显示规则匹配结果：签核/拒签/待手动，不生成文件不提交。

### 3.3 生成决策 Excel

```bash
py cli.py fetch
```

产物 `pending_signs.xlsx`：
- Sheet "待签列表"：数据 + 操作列（下拉: approve/reject/skip）+ 规则预填
- Sheet "统计摘要"：分类统计

### 3.4 编辑决策

打开 `pending_signs.xlsx`，检查「操作」列，补填或修改，保存。

### 3.5 批量执行

```bash
py cli.py process --dry-run    # 预览
py cli.py process              # 正式执行
```

### 3.6 一条龙

```bash
py cli.py run                  # fetch → 等待编辑 → process
```

### 3.7 在线即时操作

```bash
py cli.py approve 1 3 5-7     # 签核指定编号
py cli.py reject 2 4           # 拒签指定编号
py cli.py approve-all          # 全部签核
py cli.py reject-all           # 全部拒签
```

## 4. 规则配置

### 4.1 规则文件 `rules.json`

```json
{
  "auto_reject": [
    {
      "name": "规则名称",
      "conditions": [
        {"field": "字段", "op": "操作符", "value": "值"}
      ],
      "logic": "AND"
    }
  ],
  "auto_approve": [...],
  "notify": [...]
}
```

**优先级：auto_reject > auto_approve > notify > 待手动**

- `auto_reject`：命中直接拒签（多项按顺序，首个命中即返回）
- `auto_approve`：命中直接签核
- `notify`：标记需通知/确认，不自动处理

### 4.2 当前规则

```
拒签: 描述含简体字 或 为空
     + 半成品;軟體  & (单位≠ST | 类别≠PH | 无R\d{3}版本号)
     + 原材料;電控外購件 & (单位∉{M,EA} | 类别≠P)

签核: 描述以 content_whitelist 开头 + 申请人在 whitelist
```

### 4.3 操作符全集

| 操作符 | 说明 |
|--------|------|
| `equals` | 精确匹配 |
| `not_equals` | 不等于 |
| `contains` | 包含子串 |
| `starts_with` | 以...开头 |
| `starts_with_any` | 以任一逗号分隔前缀开头 |
| `starts_with_content_wl` | 以 content_whitelist.txt 任一行开头 |
| `not_starts_with` | 不以...开头 |
| `has_cn` | 含简体中文字符（zhconv 检测，繁简共用字不算） |
| `is_empty` | 为空或纯空白 |
| `regex` | 正则匹配（如 `R\\d{3}`） |
| `not_regex` | 正则不匹配 |
| `in_list` | 在逗号分隔列表中 |
| `not_in_list` | 不在列表中 |
| `in_whitelist` | 命中 whitelist.txt |
| `in_blacklist` | 命中 name_blacklist.txt |

### 4.4 可用字段

`申请人` | `描述` | `类别` | `单位` | `申请单号`

### 4.5 可编辑名单文件

| 文件 | 格式 | 作用 |
|------|------|------|
| `whitelist.txt` | 每行一个姓名 | 申请人白名单 |
| `content_whitelist.txt` | 每行一个前缀 | 描述前缀白名单 |
| `name_blacklist.txt` | 每行一个姓名 | 申请人黑名单 |

## 6. 定时任务

### 6.1 Windows 任务计划

```powershell
# 创建（每30分钟）
powershell -Command "
$action = New-ScheduledTaskAction -Execute 'py' -Argument '-X utf8 cli.py fetch' -WorkingDirectory 'D:\claude\自动签核'
$trigger = New-ScheduledTaskTrigger -Once -At (Get-Date).AddMinutes(1) -RepetitionInterval (New-TimeSpan -Minutes 30)
Register-ScheduledTask -TaskName 'AutoSignFetch' -Action $action -Trigger $trigger -Force
"

# 管理
Start-ScheduledTask AutoSignFetch     # 手动触发
Disable-ScheduledTask AutoSignFetch   # 暂停
Unregister-ScheduledTask AutoSignFetch  # 删除
```

### 6.2 Linux cron

```bash
*/30 * * * * cd /path/to/project && python .claude/auto-sign/cli.py fetch
```

## 7. 外部系统对接接口

### 7.1 CLI 命令行接口

所有功能通过 CLI 调用，返回标准退出码（0=成功, 1=失败），输出到 stdout/stderr。

```bash
py cli.py fetch -o /tmp/signs.xlsx    # 指定输出路径
py cli.py process -i /tmp/signs.xlsx  # 指定输入路径
```

### 7.2 Webhook 通知接口

**请求：** POST JSON

```json
{
  "title": "签核待办提醒",
  "summary": {"total": 12, "approve": 5, "reject": 2, "notify": 3, "manual": 2},
  "items": [{"no": "...", "applicant": "...", "desc": "...", "action": "notify", "rule": "..."}]
}
```

**对接方式：** 配置 `--webhook-url` 指向你的接收端点，可选 `--webhook-token` 做认证。

### 7.3 Excel 文件接口

`pending_signs.xlsx` 是决策数据交换格式：

| 列名 | 说明 | 外部系统可读写 |
|------|------|:--:|
| 编号 | 序号 | 读 |
| 申请单号 | NO | 读 |
| 申请人 | 申请人姓名 | 读 |
| 物料描述 | 完整描述 | 读 |
| 单位 | UOM | 读 |
| 类别 | Item Type | 读 |
| **操作** | approve/reject/skip | **读写** |
| 匹配规则 | 自动匹配的规则名 | 读 |
| 备注 | 自由文本 | **读写** |
| 处理状态 | pending/done/error | 读 |
| 处理时间 | 时间戳 | 读 |

外部系统可以：
- 读取此 Excel 做二次分析
- 修改「操作」列后调用 `process` 执行
- 在「备注」列写入外部系统信息

### 7.4 Python API 接口

```python
import sys; sys.path.insert(0, '.claude/auto-sign')

# ---- 获取待签列表 ----
from auto_sign import load_config, create_session, fetch_sign_page, parse_applications, parse_html
config = load_config('config.json')
session = create_session(config)
resp = fetch_sign_page(session, config)
soup = parse_html(resp.text)
apps = parse_applications(soup)
# apps: list[Application] — 每个含 applicant_info, radio_approve_*, radio_reject_*

# ---- 规则匹配 ----
from rules import load_rules, load_word_lists, match_rules
rules = load_rules('rules.json')
wl = load_word_lists('.claude/auto-sign')
for app in apps:
    item = {"no": "...", "applicant": "...", "description": "...", "uom": "...", "item_type": "..."}
    action, rule_name = match_rules(item, rules, wl)
    # action: "approve" | "reject" | "notify" | ""

# ---- 生成 Excel ----
from auto_sign import export_to_excel
export_to_excel(apps, rules, wl, 'output.xlsx')

# ---- 批量执行 ----
from auto_sign import process_excel
process_excel('output.xlsx', config, 'sign_records.xlsx')

# ---- 发送通知 ----
from notify import send_notification, build_summary
summary = {"total": 10, "approve": 5, "reject": 2, "notify": 2, "manual": 1}
items = [{"no": "893011", "applicant": "申正良", "desc": "...", "action": "notify", "rule": ""}]
send_notification(summary, items, ["webhook"], {"webhook_url": "https://..."})
```

## 9. 常见问题

**Q: 首次使用提示找不到 config.json？**
```bash
cp .claude/auto-sign/config.example.json config.json
```

**Q: 登录失败？**
凭证保存在 `auth.json`，删除该文件后重新运行会自动提示输入。

**Q: 如何只测试不提交？**
所有写命令支持 `--dry-run`，如 `fetch --dry-run`、`process --dry-run`。

**Q: 定时任务没生效？**
检查 `Get-ScheduledTask AutoSignFetch` 状态，确保 `py` 在 PATH 中。
