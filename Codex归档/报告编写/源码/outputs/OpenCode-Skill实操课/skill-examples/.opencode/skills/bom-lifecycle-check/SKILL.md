# BOM 失效料检查 Skill

## 输入
- BOM Excel：至少包含料号；可包含品名、品牌、数量、位号。
- 失效料号对照表 Excel：至少包含料号与状态；建议包含失效日期、替代料号、备注。

## 开始前
1. 读取工作表名和表头，向用户确认 BOM 料号列、对照表料号列与状态列。
2. 若列名明显可识别，可先提出映射建议并让用户确认。
3. 只处理用户指定的文件，不联网猜测生命周期状态。

## 匹配规则
1. 原始料号必须保留。
2. 标准化：去首尾空格、转大写；连字符默认保留。
3. 默认采用标准化后的完整料号精确匹配。
4. 同一料号多条记录时全部列出，并标记“对照表重复”。
5. 相似料号只能列为“需人工确认”，不能判定为失效。

## 输出
生成 `BOM_检查结果.xlsx`，至少包含：
- 原始料号、标准化料号、品名、数量
- 检查状态：失效 / 临近失效 / 有效 / 未命中 / 数据问题
- 失效日期、替代料号、原因或备注
- BOM 来源工作表与行号、对照表来源工作表与行号

同时在消息中给出：总行数、失效数、临近失效数、未命中数、数据问题数，以及优先处理清单。

## 禁止事项
- 不以“长得像”代替精确匹配。
- 不把“未命中”写成“有效”。
- 不擅自删除或覆盖原 Excel。
