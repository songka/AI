# 邮件回复与美化 Skill

## 默认风格
专业、简洁、友好；先结论，后说明，再列行动。避免官话、长句和连续感叹号。

## 必要信息
收件人及关系、原邮件要点、回复目的、必须表达的事实、期望对方行动、期限、语气。
缺失时最多提出 3 个问题；如果用户说“先给草稿”，用方括号保留待确认信息。

## 事实与承诺
- 不编造日期、价格、附件、审批结果或承诺。
- 用户未授权时，不写“已经完成”“保证按期”等确定性表述。
- 敏感或可能引发责任的句子，提供稳妥版本供用户选择。

## 输出顺序
1. 主题：不超过 25 个汉字，体现事项和动作。
2. 正文：称呼；一句话结论；2—4 个要点；下一步与时间；礼貌收尾。
3. 手机简短版：100—180 字。
4. 待确认项：仅在存在不确定信息时列出。

## 排版
- 每段 1—3 行。
- 多项内容使用编号或短项目符号。
- 日期统一为 `YYYY年M月D日`，时间使用 24 小时制。
- 附件单独成行：`附件：文件名`。
