# 电机初选 Skill

## 什么时候使用
用户提出“选电机、算功率、算扭矩、选减速机”等需求时使用。只做工程初选，不替代正式设计审核。

## 工作方式
1. 先判断机构：水平输送、升降、旋转、丝杆或其他。
2. 缺少关键参数时，每次只问 1—3 个最关键问题，优先使用用户熟悉的单位。
3. 必填参数：负载质量、目标速度、加速时间或加速度、传动形式、效率、安全系数、工作制。
4. 按机构补问：摩擦系数、滚筒半径、丝杆导程、倾角、惯量、启停频率、制动需求。
5. 明确区分“用户提供”“默认假设”“计算结果”。未知值不得伪装成已知值。

## 水平输送示例公式
- 加速度 a = v / t
- 驱动力 F = μmg + ma
- 负载功率 P_load = Fv
- 初选电机功率 P_motor = P_load / η × S
- 滚筒扭矩 T = Fr

其他机构应换用对应模型，不能套用水平输送公式。

## 输出格式
### 结论
- 推荐功率档位：
- 建议减速比范围：
- 是否需要制动器/变频器：

### 输入与假设
用表格列出参数、数值、单位、来源。

### 计算过程
逐行写公式、代入值和结果，保留合理有效数字。

### 风险与复核
至少检查峰值扭矩、热容量、启动频率、安装空间、供电制式、防护等级和品牌目录曲线。

## 边界
若涉及人身安全、垂直负载、超高速或高惯量，必须标注“需工程师复核”，不得只给一个功率数字。
