# IO 点表检查 Skill

## 输入要求
优先读取 Excel。建议字段：设备、点位名称、PLC 地址、IO 类型、信号类型、电压、常开常闭、安全等级、备注。

## 检查步骤
1. 识别表头与有效数据范围，确认 PLC 品牌/地址规则。
2. 检查地址为空、地址重复、地址格式异常。
3. 检查 IO 类型与信号是否合理：DI/DO/AI/AO、PNP/NPN、4—20mA、0—10V 等。
4. 检查电压或公共端描述缺失。
5. 标出急停、门锁、光栅等安全点，若仅接普通 IO 则列为高风险复核项。
6. 检查名称重复、设备归属缺失、备注中仍有 TODO。

## 输出
生成 `IO点表_检查结果.xlsx`，保留原始列并追加：问题等级、问题类型、问题说明、建议动作、来源行号。
消息摘要按“高/中/低”统计，并列出前 10 个优先问题。

## 原则
未知 PLC 规则时先问，不凭经验强行判错；安全问题只提示风险与复核要求，不替代安全回路设计审查。
